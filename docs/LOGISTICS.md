# 物流中心设计

## 目标

统一管理 UPS、FedEx、USPS、Shippo 和其他超长件物流平台，减少重复登录和人工比价。

## 发货数据

每票货保存发件人、收件人、订单号、箱数、每箱长宽高、重量、单位、超长标记、承运商、服务等级、报价、附加费、标签、Tracking、预计和实际到货时间。

## 超长件

对 106–120 英寸等超长包裹单独标记，显示超长费、不可寄原因和替代承运商。系统不得只显示基础运费而隐藏附加费。

## 比价与推荐

保存历史真实成交运费。相似尺寸和重量再次出现时，展示上次承运商、价格和时效，并说明推荐依据；第三方实时价格必须标注获取时间。

## 客户通知

生成 Tracking 后可通知客户；异常、延迟和签收状态进入消息中心。

## 权限与密钥

物流账号和 API 密钥只保存在部署环境。客户只查看自己的 Tracking，不查看内部采购价或承运商折扣。
