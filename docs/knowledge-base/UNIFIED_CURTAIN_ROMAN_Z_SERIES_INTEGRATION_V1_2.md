# Braun 统一窗帘、罗马帘、臻品 Z 系列系统融合需求 V1.2（审议稿）
日期：2026-10-09
状态：需求设计，**非代码实施**；不修改现有计算器，不部署，不冻结 V1.0。

## 目标
将此前的布艺窗帘 Jin/Braun 报价、Romalux 罗马帘、臻品 Z 系列报价及其他窗饰纳入同一 Braun 门户。一个客户、一个订单可包含多个房间/窗口、产品类型和无限供应商；统一报价、订单、收款、生产、运输、安装、发票、售后、报表。官网公开，经营门户私有；中英文、手机/平板/电脑。

## 架构原则
- 统一报价页面与订单数据模型，但每一行绑定独立价格引擎、客户专属价格表版本、供应商及来源。
- 不交叉套价：Jin、Braun、Romalux、Z 系列的规则分别审核；缺少权威价格表时阻止正式报价，不用其他客户或其他系统代替。
- 原始人民币成本、USD 销售价、报价汇率（业务默认 6.7 待源文件复核）、实际汇率、运费估算、实际物流账单分别记录。
- 客户价格权限隔离，工厂成本不对外；原始文件、旧版价格、已确认订单快照不可覆盖。
- 统一知识库支持 Excel/CSV/PDF/Word/图片/ZIP/邮件及附件，上传先入待审区，管理员批准版本后进入正式计算。

## 各产品引擎
1. 布艺窗帘：按 Jin/Braun 现有权威价目表及高度/双层/工艺规则逐项核对；此前曾确认双层×1.8、超过 120 英寸附加、超过 244 英寸翻倍，但须限定适用产品/客户和公式顺序。
2. Romalux 罗马帘：DR-01 一体双层，原始面料罗马帘基础价 Bf×1.8；DR-02 双独立轨 Bf+Bs；各层附加独立计算；宽和高分别向上取整至整数英寸矩阵格；TWIN 独立，不误认作 DR-01；超过范围或缺失价格不得自动签发。附件和电机按对应版本。
3. 臻品 Z 系列：保留 Z 历史算法及最新版产品目录作候选源；此前确认的「人民币表价÷6.7×2.5×10」、不足 1㎡按1㎡、AOK 电机 $50/个、遥控 $10/个不打折，与历史 GitHub 6.5/2.65/1.7/电机折扣保底有冲突，需逐型号及版本审核，不自动替换。
4. 其他窗饰：卷帘、斑马帘、蜂巢帘、竹帘、蝴蝶帘等建立独立类别与供应商规则；缺价进入人工审核。

## Z 系列物流独立引擎
详见 `docs/knowledge-base/Z_SERIES_PRICING_SHIPPING_AUDIT_2026-10-09.md`。
历史 `public/z-roman/roman_db.js` 采用：宽差≤8英寸同箱、每箱最多5条明细、包装长约最大宽度×2.54+15cm；材积重量长宽高/6000；实重估算按面积×2.5kg且单件最低1.5kg；历史整单计费重取总材积与总实重较大值；预估运费 $8.5/kg。多箱应逐箱计费还是整单取较大值、配件重量、运费是否与成本系数重复计入，必须审批。不得与通用 Shippo 国内运输的英寸磅/139 算法混用。

## 统一订单流程
客户与房间/窗口 → 选择产品/面料/系统/尺寸 → 独立引擎计算 → 汇总报价及税费运费 → 客户确认 → 审核已到账并分配的清算收款 → 按供应商拆分生产单 → 供应商确认具体版本 → 生产进度 → 分供应商多运单 → 到货/安装 → 财务对账及售后。
- 客户收款审核完成前不向供应商释放生产订单。
- 每供应商独立采购单、确认、变更、取消、物流、成本；无限供应商。
- 订单号稳定，报价/生产单各自版本化；修改影响生产的项目须新版本确认，新增费用支付后才释放受影响的新增生产。
- 客户、订单、角色、操作四维权限；支持管理员代入查看及审计；多设备编辑冲突处理。

## 统一知识库关键实体
Customer, Supplier, ProductFamily, ProductVariant, Fabric, Color, Hardware, PricingSource, PriceVersion, CustomerPricePolicy, Quote, QuoteLine, RoomWindow, Order, OrderLine, SupplierPO, POAcknowledgement, Package, Shipment, CarrierRate, FreightInvoice, PaymentAllocation, Invoice, CreditMemo, AfterSalesCase, FileAsset, Approval, AuditEvent。
每条报价明细保留引擎 ID、规则版本、原始币种、公式快照、供应商、客户折扣及价格来源。图片与型号须审核关联，不凭外观猜测。

## 必须通过的融合验收案例
- 同一订单混合布艺窗帘、DR-01、DR-02、Z 罗马帘、Z 卷帘，逐行调用正确引擎并独立记录来源。
- 同一产品对不同客户使用各自价格/折扣；不可泄露成本。
- 罗马帘 39 5/8 英寸宽度矩阵取 40，保留原始尺寸。
- Z 系列多箱、多数量、纯配件、超长、不同运费口径测试；运费只计一次。
- 一个订单拆给3个供应商，分别确认和发货；任何单个供应商异常不影响其他已批准生产。
- 已到账但未清算/未分配/未审核的款项不允许生产。
- 多窗口报价生成单页或分页发票时金额、明细、税、运费准确；历史快照不可改。
- 手机/平板/电脑中英文、角色权限、审计、备份恢复、历史未结清应收应付100%核对。
