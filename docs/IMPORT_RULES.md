# Excel 导入规则

## 支持来源

批发销售工作簿（汇总、Paul、林、彭）、Jin `Commerce订单汇总`，后续扩展 KT 支出、库存和价格表。

## 安全流程

上传文件 → 识别类型 → 标准化 → 预览 → 警告与重复检查 → Owner 确认 → 暂存批次 → 逐条审核 → 生成正式记录。未经确认不得覆盖数据库。

## 关键规则

- USD 与 RMB 分开保存，禁止自动把人民币改成美元。
- 空金额保持为空，不填 0。
- 异常长数字不作为金额。
- `CWF67635` 统一为 `CWF 67635`。
- Excel 日期序列转换为 ISO 日期。
- 同一 PO 的不同产品明细不得因订单号相同而删除。
- 合并汇款保留原始说明，待人工分配。
- 保存来源文件、工作表、原始行号和原始 JSON。
- 使用 SHA-256 拦截重复文件。
- 导入批次和来源行建立唯一约束。

## 回滚

尚未生成正式业务记录的批次可以安全回滚；已生成订单、支出或付款的批次必须使用目标记录回滚流程，不能直接删除暂存批次。

## 币种警告

批发销售“汇总”页支出多数为人民币但可能包含少数美元，自动解析必须标记待核对，Owner 审核后才能提交正式财务。
