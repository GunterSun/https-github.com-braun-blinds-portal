# Real Data Migration Checklist

## 目标
把现有 Excel、PDF、图片和历史业务记录安全迁移到 Braun Smart Portal，并支持预览、审核、追溯和回滚。

## 第一批：产品与价格
- Braun 产品目录
- Jin 产品目录与价格表
- KT 产品和工厂价格
- Drapery、Roman、Roller、Zebra、Honeycomb、Shutters、Blinds
- Curtain Rod、Motorized Track、Motor、Hardware
- 客户等级与专属折扣
- 安装费、运费和特殊工艺附加费

### 校验
- 产品名称和 SKU 去重。
- Shutters 与 Blinds 分类不能混入普通 Shade。
- 双层规则、倍率和最低价逐条对照。
- USD 与 RMB 币种不依靠单元格颜色猜测。
- 价格表保存来源、版本和有效日期。

## 第二批：客户与历史订单
- 客户名称、公司、电话、邮箱和地址
- Quote、Invoice、付款和欠款
- 工厂支出、加工费、材料款和运费
- Tracking、安装日期和付款方式

### 校验
- 五位数订单号标准化。
- `68735`、`CWF68735`、`CWF 68735` 识别为同一订单候选，但必须人工确认后合并。
- 重复客户先生成合并预览。
- 修改客户主地址不得改变历史 Invoice 地址快照。

## 第三批：库存与供应商
- 面料、样册、电机、轨道、窗帘杆、配件和包装
- Jin、KT 和其他工厂/供应商
- 库存数量、单位、批次、卷号和序列号

### 校验
- Yard、Foot、Inch、Piece、Set、Box、Roll、Panel 明确映射。
- 不允许空白数量自动变成零。
- 库存余额必须可由库存流水重建。

## 第四批：文件与知识资料
- 产品说明书
- 安装手册
- 双语 PDF
- 专利资料
- 工程照片和安装照片
- 价格表与历史版本

### 校验
- 保存原始文件 SHA-256。
- 保存来源、上传人、上传时间和可见范围。
- 旧价格表保留历史，但不得作为默认报价来源。
- 客户无权查看成本、利润、内部批注和隐藏工作表。

## 导入流程
1. 上传文件。
2. 文件安全检查和 SHA-256 去重。
3. 识别文件类型与字段。
4. 映射到 BDS 标准字段。
5. 生成暂存数据和错误报告。
6. 人工逐条或批量审核。
7. 确认后写入正式数据库。
8. 生成导入批次、审计记录和回滚点。

## 禁止事项
- 禁止直接用未审核 Excel 覆盖生产数据库。
- 禁止根据字体、背景颜色或位置自行判断币种而不保留依据。
- 禁止删除历史记录来解决重复问题。
- 禁止在导入失败时显示成功。
- 禁止把演示订单、假客户或静态 KPI 导入 production。

## 验收样本
每种来源至少使用一个真实匿名样本：
- Braun 价格表
- Jin 价格表
- KT 支出表
- 批发销售汇总
- 单页 Invoice
- Shutters 产品样本
- Blinds 产品样本
- 多币种、多工厂、多箱运输订单

## 完成定义
迁移完成必须满足：记录数量对账、金额对账、币种对账、重复报告、错误报告、审计记录、回滚测试和用户抽查全部通过。
