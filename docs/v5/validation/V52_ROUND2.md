# V5.2 第二轮验证 · 2026-10-12

## 性能测量

执行真实 readReviewPage/readCandidates，customers/orders/customer_orders 每表分别为 1 万、10 万、50 万条虚构记录。每场景 3 次预热、20 次计时，P95 为排序后的第 19 个样本。单进程内存 SQLite，无并发、不含网络、HTTP、D1 或 R2；不是生产性能验收。

| 每表记录 | 客户搜索 P95 | 复杂无匹配搜索 P95 | 候选查询 P95 |
|---|---:|---:|---:|
| 10,000 | 2.51ms | 2.78ms | 1.79ms |
| 100,000 | 26.99ms | 30.03ms | 17.10ms |
| 500,000 | 141.64ms | 169.88ms | 107.44ms |

15 个场景、每场景 23 次调用均无错误。这是读模型调用错误率，不是线上请求错误率。完整环境、查询计划、分页耗时、SQL 数量、返回行数见 [原始测量结果](v52-performance.json)；复现脚本 scripts/benchmark-v52.mjs。

EXPLAIN 显示 ID 游标及引用查询使用主键，客户子查询按客户主键查找；包含匹配仍逐行判断，候选可能遍历大量订单。本地样本低于建议目标，不意味着已解决真实规模性能问题。日期截取、包含搜索、并发和部署环境尾延迟仍须在完整脱敏隔离副本与 D1 测量，本轮未新增生产索引。

## 浏览器检查

使用实际页面组件打包，替换 API 为虚构长字段样例，没有生产数据库或真实客户。内置浏览器检查 320/390/768/1024/1440px；扣除滚动条后 clientWidth 分别为 305/375/753/1009/1425px，scrollWidth 与之相同，无横向溢出。五种容器完成搜索、翻页、候选展开；60,712 字符详情在限定高度区域内滚动。点击复制全文显示成功反馈。

范围限制：样例没有加载全站布局 CSS；这不是完整应用端到端测试，也不是 iOS Safari 或真实 iPhone/iPad 验收。完整页面 CSS 与真实设备行为仍需验证。截图保存在本地隔离验证目录，不包含客户信息。

## 读取标识和长字段

API 新增请求 UUID、读取时间、查询与返回内容的 SHA-256。此标识仅描述本次读取内容，不是数据库快照或跨页冻结。正式确认前仍必须在事务中重新核验源版本，不能把该哈希当作确认凭据。

详情默认只显示前 2,000 字符，可展开全文；区域限定高度并支持键盘聚焦滚动。复制使用全文，失败提示手动选择。显示截断不修改原始数据。

16 项隔离自动测试通过，包括请求标识独立、内容不变时哈希稳定、内容变化后哈希变化；类型检查及本地构建通过。未部署生产、未执行迁移、未开放关联写入。
