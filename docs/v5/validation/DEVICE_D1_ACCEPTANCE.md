# V5.2 真机与远端 D1 验收执行单

日期：2026-10-13。基线 `ebe4c847f3661c9c41297440dc67f55071806cee`，GitHub CI 已通过。本执行单不授权上线、正式迁移或历史关联写入。

## 当前可执行范围

本地隔离配置没有 Sites project_id；D1 ID 是本地占位值，不能作为远端目标。已列出的 7 个现有 Sites 没有明确标注为本次 V5 隔离验收环境，不能仅凭名称将其中一个视为测试库。尚需确认专用测试站点、数据库 ID、测试数据来源及访问方式。

不得对现有正式站点运行大数据量压力测试，不使用旧站点的真实客户库作为替代。只读查询仍可能消耗生产资源；只读并不免除环境隔离要求。

## 环境进入条件

- 明确独立站点地址、数据库绑定及真实远端数据库 ID，与生产 ID 不同。
- 数据仅为虚构记录或经批准、已核验脱敏的历史样本；不包含原密码、session、签名、令牌、附件访问凭据。
- 测试账号与生产独立；只读工作台使用有效 Owner 会话。不要在报告或聊天粘贴令牌。
- 页面构建对应验收基线；无支付、通知邮件、供应商下单等外部副作用。
- 加载样本属于测试库准备写入，必须与只读测量阶段分开。只读测量期间禁止迁移、清表或修改样本。
- 发布测试站点也需明确目标；当前尚未建立或发布该远端环境。

每次记录设备型号、OS、浏览器版本、横竖屏、浏览器缩放/文字大小、测试时间和基线提交。截图需仅含测试数据。

| 编号 | 操作 | 合格标准 |
|---|---|---|
| M01 | Owner 登录，打开工作台，按客户及单号搜索 | 输入、键盘与搜索按钮可用；结果明确显示查询范围 |
| M02 | 设置日期范围，搜索无结果及有结果各一次 | 日期可操作；无结果不显示成系统故障；修改条件后从首批开始 |
| M03 | 下一页、上一页、分类筛选、刷新 | 页内容与游标正确，分类统计仅为本页；刷新建立新批次 |

| M05 | 展开 60,000 字符以上原文、收起、复制全文 | 页面无横向溢出；详情内部可滚动；复制未截断；失败提示可见 |

| M08 | 测试网络断开/恢复，再次搜索 | 显示错误并可重试；不将失败当作空记录或保留为最新结果 |
| M09 | 非 Owner 或已退出会话访问 | 不显示审核资料；API 返回 401/403 |

执行设备：iPhone Safari、iPad Safari（竖屏和横屏）、电脑浏览器。320/390/768/1024/1440px 模拟已测，但不能填写为以上真机通过。复制到测试用记事处核对字符数后清除，避免长期保留客户信息。

## 远端 D1 测量矩阵

每个规模分别准备每张核心表 10,000、100,000、500,000 条测试记录，记录各表真实数量、索引、库大小。加入有明确引用、缺失引用、重复线索、不同币种、长文档、多窗口、多供应商和签发版本冲突样例，避免只有均匀平铺数据。

每场景 5 次预热 + 50 次正式测量；先并发1，稳定后再并发3。每轮设置明确请求总数与停止条件，禁止无限循环压测。

| 编号 | 场景 | 要记录的数据 |
|---|---|---|
| D01 | 无筛选首批、深游标翻页 | 端到端耗时、D1耗时、rows_read/rows_written、返回主记录与引用数量 |
| D02 | 客户/单号包含搜索，常见词与不存在词 | 同上；EXPLAIN QUERY PLAN 与索引使用情况 |
| D03 | 日期范围 + 客户条件 | 同上；记录日期截取导致的扫描范围 |
| D04 | 候选首批与后续批次 | 候选数、邮箱/项目/单号匹配线索、扫描行数 |
| D05 | 报价/生产单的多层引用展开 | SQL次数、引用数量、缺失引用结果、返回体字节数 |
| D06 | 读取超时/受控错误 | API状态、错误提示、取消/恢复行为；无自动重复写入 |

P95 使用50个正式样本按耗时排序后第48个；预热不计入。普通搜索目标≤1秒，复杂搜索≤2秒，均为包含网络的端到端目标；同时报告 D1 内部耗时，不能用它替换端到端指标。记录 P50/P95/max、错误数、超时数、SQL次数、返回体大小。正常场景目标无错误，受控错误单列不混入成功样本。

查询计划只对实际参数化查询执行。测试报告记录执行环境、样本分布、索引、基线提交及查询类别，不记录敏感绑定值。D1运行元数据如工具可获取则记录，不可获取标为 unavailable，不填0。

如果出现持续超时、非预期写入、权限错误或跨客户泄漏，立即停止该轮并保留诊断信息。不得通过删除或修改历史数据让测试“通过”。

## 只读与一致性证据

测量前后比较测试表行数及规范化内容摘要；若存在外部测试写入，暂停或重做，不把变化归因不明的数据判为通过。记录 API 的读取UUID/时间/内容哈希及分页上界。它们不是数据库一致性快照，正式确认前仍须重读并进行原子版本校验。
