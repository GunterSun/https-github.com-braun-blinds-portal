# Braun Smart Portal V1 — 中英文实施清单

## 目标
把全系统中英文要求拆成 Codex 可直接执行、可测试、可发布的工程任务。V1 的所有角色、核心页面、PDF、通知、签名与 AI 必须支持 English / 中文。

## 一、语言基础架构
- 建立统一语言资源目录，例如 `locales/en` 与 `locales/zh-CN`。
- 禁止在组件、API 响应模板和 PDF 模板中直接写死界面文字。
- 语言键使用稳定业务含义，不使用页面位置命名。
- 缺失翻译时开发环境显示明确错误，CI 与 production 发布必须失败。
- 保存每个用户的 `preferred_locale`，仅允许 `en`、`zh-CN`。
- 登录前可选择语言；登录后默认使用用户设置。
- 切换语言不得清空表单、草稿、附件、筛选、分页或当前路由。

## 二、五类角色
### Owner
- Dashboard、客户、订单、财务、工厂、库存、物流、安装、设置和审计全部双语。
- KPI 名称、警告、审批状态和下钻页面全部双语。

### Sales
- CRM、测量、产品配置、Quote、Invoice、付款和跟进记录全部双语。
- 客户可见文本与内部文本必须分开，不能因为切换语言泄露成本或利润。

### Factory
- 生产任务、材料、尺寸、工艺、质检、异常和发货状态全部双语。
- 产品名称显示固定中英文术语；客户售价和利润继续隐藏。

### Installer
- 今日任务、导航、联系人、产品规格、检查表、照片、异常、完工签名和离线提示全部双语。
- 尺寸统一显示 `72"` 或 `72 5/16"`；整数英寸不显示 `0/16`。

### Customer
- Quote、Invoice、付款、Tracking、安装、签名和保修页面全部双语。
- 客户签名页面可以选择 English、中文或中英双语。

## 三、核心页面优先级
1. 登录、忘记密码、双重验证和账号设置。
2. Dashboard 与全局导航。
3. Customer → Project → Room → Window。
4. 测量与产品配置器。
5. Quote、Invoice、Payment 与电子签名。
6. Factory、Inventory、Shipping、Installation。
7. AI Assistant、企业搜索与通知中心。
8. 设置、角色权限、审计和发布中心。

## 四、业务数据与翻译边界
以下内容不得自动翻译或改写：
- 客户姓名、公司名称、地址、电话、邮箱。
- Order、Quote、Invoice、PO、Tracking 编号。
- SKU、系列、型号、面料编号、颜色代码和电机型号。
- 金额、币种、税率、日期、尺寸和签名姓名。

以下内容必须来自受控术语表：
- 产品类型、安装方式、控制方式、状态、异常原因、检查项和客户确认项。
- `Shutters = 百叶窗`，`Blinds = 百叶帘`，不得混用。

## 五、PDF 和打印文件
支持三种输出：
- English only
- 中文版
- English / 中文 bilingual

覆盖：
- Quote
- Invoice
- Receipt
- Purchase Order
- Factory Work Order
- Packing List
- Installation Checklist
- Completion Certificate
- Warranty Certificate

PDF 必须满足：
- 中英文不重叠、不乱码、不截断。
- 签名、验证编号、版本和金额在三种语言版本中一致。
- 同一文档不同语言版本引用同一业务记录和同一版本 SHA。

## 六、通知与消息
- Email、SMS、门户通知和签名邀请根据收件人语言生成。
- 发送前允许工作人员预览并切换语言。
- 模板保存 `template_key + locale + version`。
- 缺少对应语言模板时不得静默发送另一种语言。
- 自动催款、安装提醒、发货通知和付款收据必须经过同样规则。

## 七、AI 双语
- 支持中文、英文和混合输入。
- 同义词映射到同一实体和同一业务操作。
- AI 回答默认使用当前用户语言，可明确要求另一种语言。
- 引用的订单号、金额、尺寸、产品代码和 Tracking 不得翻译改写。
- AI 不得因语言差异绕过角色权限。

## 八、测试要求
- 每个核心页面分别用 English 和中文执行同一流程。
- 在填写一半表单时切换语言，数据不得丢失。
- 两种语言下 API 权限与返回字段完全一致。
- 中英文 PDF 金额、尺寸、版本、签名和页数一致。
- 移动端、平板和桌面端均通过。
- 长中文、长英文和无空格产品代码不破坏布局。
- 所有语言键执行自动扫描，缺失、重复或未使用键生成报告。

## 九、发布闸门
以下任何一项失败，不得发布 V1：
- 核心页面存在写死文字。
- 任一角色出现缺失翻译或权限差异。
- PDF 中文乱码、截断或金额不一致。
- 切换语言造成草稿、照片或签名丢失。
- 通知使用错误语言。
- AI 在两种语言下返回不同权限范围的数据。
