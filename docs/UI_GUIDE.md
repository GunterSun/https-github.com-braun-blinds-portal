# 界面设计规范

## 总体风格

专业、清晰、适合日常业务操作。避免复制其他网站的视觉；Braun Smart Portal 使用独立品牌风格。页面必须支持中文和英文、手机、平板和电脑。

## 导航

统一从 `/hub` 进入。相同业务只保留一个主入口，避免客户、订单和销售线索重复出现。按角色隐藏无权限模块，但服务端仍必须校验权限。

## 状态表达

模块和按钮明确区分：可使用、正在整合、计划中。未实现功能不得显示成可操作状态。订单、付款、生产、物流和安装状态采用一致词汇。

## 表格与表单

- 字体可读，行高足够，手机端可横向滚动或卡片化。
- 金额旁始终显示币种符号或代码。
- 危险操作采用二次确认。
- 保存成功、失败和字段错误必须有明确提示。
- 长表单支持分区、草稿和自动保存状态提示。

## Invoice

一页式为默认目标；公司、客户、订单、项目、产品、数量、价格、税、安装费、付款状态和余额清晰显示。已付款标记醒目但不遮挡内容。

## 数据真实性

工作台空数据应显示“暂无数据”，不能用演示数字填充。所有 KPI 显示统计范围和更新时间。
