# 测量与报价尺寸精度：1/16 英寸

## 适用范围
BRN-020 手机测量、BRN-021 产品配置与价格、Quote、Invoice、订单、工厂单、采购单、安装单和 AI 查询中，所有以英寸记录的窗位和产品尺寸必须精确到 **1/16 英寸**。

## 标准表示
- 数据库不使用二进制浮点数直接保存英寸。
- 标准存储字段为 `measurement_sixteenths`，单位是 1/16 英寸的整数。
- 示例：
  - 72" = 1152
  - 72 1/16" = 1153
  - 72 1/2" = 1160
  - 72 15/16" = 1167
- 可同时保存 `source_value`、`source_unit` 和 `entered_display`，用于追溯原始输入。

## 用户输入
支持以下格式：
- `72`
- `72 1/16`
- `72-1/16`
- `72.0625`
- 整数英寸下拉框 + 分数下拉框

分数选择固定为：
`0, 1/16, 1/8, 3/16, 1/4, 5/16, 3/8, 7/16, 1/2, 9/16, 5/8, 11/16, 3/4, 13/16, 7/8, 15/16`。

## 厘米输入
- 厘米可输入小数。
- 转换为英寸后，必须按照产品或工作流规则明确取整到 1/16 英寸。
- 系统显示转换前数值、转换后数值和取整方向。
- 不能静默改变客户输入。

## 原始尺寸与成品尺寸
必须分开保存：
- `measured_width_sixteenths`
- `measured_height_sixteenths`
- `measured_depth_sixteenths`
- `deduction_sixteenths`
- `addition_sixteenths`
- `finished_width_sixteenths`
- `finished_height_sixteenths`

Inside Mount 扣减、Outside Mount 增加以及工厂成品尺寸均由版本化规则计算，不得覆盖原始测量值。

## 三点测量
宽度和高度可记录左/中/右或上/中/下三组值，每个值均精确到 1/16 英寸。系统按照产品规则选择最小值、最大值或人工确认值，并保存决策来源。

## 报价与文档
- Quote 和 Invoice 必须显示规范分数格式，例如 `72 5/16 in`，不显示长小数。
- 已发送 Quote、已签 Invoice 和正式订单保存尺寸快照。
- 后续修改测量数据不得改变历史文档。
- 计算器、API、AI 和 Excel 导入必须使用相同的整数 1/16 英寸标准。

## API 示例
```json
{
  "width": {
    "sixteenths": 1160,
    "display": "72 1/2 in",
    "decimal_inches": "72.5000"
  }
}
```

写入接口拒绝无法精确转换或超出允许范围的值，并返回明确错误，而不是自动写入零。

## Excel 导入
支持：
- 整数英寸
- 小数英寸
- 文本分数（如 `72 5/16`）
- 分开的整数列与分数列

导入预览必须显示标准化前后结果；存在模糊值、非法分母或超过 1/16 精度的值时进入人工审核。

## 验收测试
- 16 个分数档位均能正确输入、保存、显示和导出。
- `72 1/16` 往返保存后仍为 `72 1/16`。
- 不出现 `72.062499999` 等浮点误差。
- Quote、Invoice、工厂单和安装单显示完全一致。
- IB/OB 规则的加减结果保持 1/16 英寸精度。
- Excel、手机、网页、API 和 AI 对同一尺寸返回相同结果。
- 空白值保持空白，不转换为 0。
- 超出产品限制时阻止正式报价并给出明确原因。
