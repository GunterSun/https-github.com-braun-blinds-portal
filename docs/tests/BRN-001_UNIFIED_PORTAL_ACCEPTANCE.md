# BRN-001 统一门户验收清单

## A. 唯一入口

- [ ] `/hub` 是统一业务入口。
- [ ] 正式域名目标明确为 `portal.braunblinds.com`。
- [ ] 旧门户未继续新增独立功能。
- [ ] 旧入口已设置跳转、只读提示或停止维护说明。
- [ ] 用户不会因为多个入口而进入不同版本的数据。

## B. 登录与角色

- [ ] Owner、Sales、Factory、Installer、Customer 使用同一登录页。
- [ ] 登录成功后统一进入 `/hub`。
- [ ] 停用账号无法登录。
- [ ] Session 到期和退出登录正常。
- [ ] 未登录用户无法访问受保护页面。

## C. 菜单权限

- [ ] Owner 可见全部管理模块。
- [ ] Sales 不能查看未授权财务、系统设置和其他销售的数据。
- [ ] Factory 只能查看被分配的生产内容。
- [ ] Installer 只能查看被分配的安装任务。
- [ ] Customer 只能查看自己的业务数据。
- [ ] 不可访问模块不显示，直接访问 URL 时也会被拒绝。

## D. 单一数据源

- [ ] 同一客户不会在不同模块形成多个冲突主记录。
- [ ] 同一订单号只对应一个主订单。
- [ ] Quote、Invoice、付款、工厂、物流和安装可追溯到同一订单。
- [ ] 客户付款状态在订单和 Invoice 页面一致。
- [ ] 数据修改后不会只更新一个旧门户。
- [ ] 旧数据迁移保留来源和审计记录。

## E. 统一导航

- [ ] 工作台、客户、报价、订单、Invoice、收款可正常进入。
- [ ] 工厂、导入、物流、安装、财务等模块按角色显示。
- [ ] 手机端菜单可展开、关闭和导航。
- [ ] 当前页面有明确选中状态。
- [ ] 不存在点击无反应的假按钮。

## F. 模块状态

- [ ] 可使用模块经过真实操作验证。
- [ ] 开发中模块明确显示“开发中”。
- [ ] 暂未启用模块不能伪装为已完成。
- [ ] 首页不显示无来源的假 KPI、假订单或假收款。
- [ ] 空数据时显示真实空状态。

## G. 迁移与对账

- [ ] 三个旧门户的有效功能已完成清单盘点。
- [ ] 客户数量迁移前后完成核对。
- [ ] 订单数量、订单号和金额完成核对。
- [ ] Invoice 状态和实收金额完成核对。
- [ ] USD 与 RMB 未在迁移过程中混淆。
- [ ] 重复客户和重复订单有处理记录。
- [ ] 迁移前有备份，失败时有回滚方案。

## H. 安全

- [ ] Customer 无法通过修改 URL 查看其他客户资料。
- [ ] Factory 和 Installer 无法查看未分配订单。
- [ ] 敏感成本和利润只对授权角色开放。
- [ ] 登录 Cookie 使用 HttpOnly 等安全设置。
- [ ] 关键操作写入审计日志。
- [ ] API 错误不泄露密钥、密码哈希或服务器堆栈。

## I. 设备兼容

- [ ] 桌面电脑可用。
- [ ] iPhone 和 Android 手机可用。
- [ ] iPad 和其他平板可用。
- [ ] 表格在窄屏可横向滚动或切换卡片视图。
- [ ] 主要按钮大小适合触摸操作。
- [ ] 中英文切换不会破坏布局。

## J. 部署与域名

- [ ] `main` 分支代码已构建成功。
- [ ] 数据库迁移在目标环境执行成功。
- [ ] 必要环境变量已在部署平台配置。
- [ ] 正式域名 DNS 已指向真实部署。
- [ ] HTTPS 正常。
- [ ] `/hub`、登录、订单和 Invoice 已在线实际测试。
- [ ] GitHub 合并、部署、数据库和 DNS 状态分别记录。

## K. 最终验收

- [ ] Owner 用真实账号完成一次登录和订单查询。
- [ ] Sales 用真实测试账号完成报价和订单访问。
- [ ] Factory 查看一张分配订单。
- [ ] Installer 查看一项安装任务。
- [ ] Customer 查看自己的 Invoice，且无法查看其他客户内容。
- [ ] 一个真实订单从客户、Invoice、付款、工厂、物流到安装的数据一致。
- [ ] 旧入口不会再把用户带到不同数据版本。
