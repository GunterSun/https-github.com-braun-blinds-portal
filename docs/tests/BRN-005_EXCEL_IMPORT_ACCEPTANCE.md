# BRN-005 Excel 导入中心验收清单

## A. 权限

- [ ] 未登录用户访问 `/data-import` 被拒绝或跳转登录。
- [ ] Sales、Factory、Installer、Customer 无法访问导入页面和 API。
- [ ] Owner 可以上传、确认、查看历史和回滚。

## B. 文件识别

- [ ] `jin汇总1.xlsx` 被识别为 `jin-commerce`。
- [ ] `批发销售*.xlsx` 被识别为 `wholesale-sales`。
- [ ] 未知格式显示明确错误，不写入数据库。
- [ ] 文件解析失败时不会产生空批次。

## C. 币种

- [ ] USD 与 RMB 分别统计。
- [ ] 人民币不会显示为美元符号。
- [ ] 美元不会保存为 RMB。
- [ ] 空金额保持空值。
- [ ] 币种不明确的支出显示警告。

## D. 标准化

- [ ] `CWF67635` 转换为 `CWF 67635`。
- [ ] Excel 日期序列转换为正确日期。
- [ ] 异常长数字不会作为金额。
- [ ] 同一订单的不同产品明细都被保留。
- [ ] 每条记录显示来源工作表和原始行号。

## E. 确认导入

- [ ] 浏览器正确计算 SHA-256。
- [ ] Owner 点击确认后建立一个批次。
- [ ] 成功后显示批次编号。
- [ ] 相同文件第二次确认返回重复提示。
- [ ] 单次超过 5,000 条记录被拒绝。
- [ ] 暂存导入不会修改正式订单、付款或支出。

## F. 导入历史

- [ ] `/data-import/history` 显示最近批次。
- [ ] 显示文件名、类型、记录数、警告数、状态和确认时间。
- [ ] 已生成正式记录数量显示正确。
- [ ] 无批次时显示空状态，不报错。

## G. 回滚

- [ ] 未生成正式记录的 confirmed 批次可回滚。
- [ ] 回滚后批次状态为 `rolled_back`。
- [ ] 回滚后导入明细状态同步更新。
- [ ] 已回滚批次不能再次回滚。
- [ ] 已生成正式业务记录的批次禁止直接回滚。
- [ ] 回滚操作写入审计日志。

## H. 界面

- [ ] 中文和英文可以切换。
- [ ] 手机、平板和电脑布局可用。
- [ ] 500 条预览时页面仍可滚动操作。
- [ ] 警告记录视觉上明显。
- [ ] 确认按钮在处理中不可重复点击。

## I. 发布前检查

- [ ] 数据库已创建 `import_batches` 和 `import_rows` 表。
- [ ] 生产环境 Session 和 Owner 权限正常。
- [ ] API 返回错误时不泄露密钥或堆栈信息。
- [ ] 备份现有数据库后再首次启用。
- [ ] 在测试环境使用两份真实 Excel 完成一次完整演练。
- [ ] GitHub 合并状态、部署状态和数据库迁移状态分别记录。
