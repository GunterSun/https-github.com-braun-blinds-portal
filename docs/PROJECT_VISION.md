# 项目愿景：Braun Smart Portal

## 定位

Braun Smart Portal 是 Braun Blinds 的统一业务系统，目标是逐步替代分散的 Excel、多个旧门户和重复录入流程。系统同时承担 ERP、CRM、客户门户、报价、Invoice、收款、工厂、物流、安装、财务与资料管理功能。

## 核心目标

1. 所有业务围绕唯一订单号管理。
2. 老板、销售、工厂、安装工和客户从同一入口登录。
3. Braun 与 Jin 计算器、Quote、Invoice、收款、采购、物流和安装形成完整链路。
4. 美元和人民币分别保存，不因显示或汇总而错误换币。
5. 支持真实 Excel 数据安全导入、预览、去重、审核与回滚。
6. 手机、平板和电脑均可使用，中英文一键切换。
7. 所有按钮必须对应真实功能；未完成模块必须明确标记。

## 一个订单，一个工作空间

订单详情应集中显示：客户、联系人、地址、产品、尺寸、报价、Invoice、付款、工厂、材料、加工费、物流、Tracking、安装、照片、文件、沟通记录和利润。

## 统一门户

- 统一入口：`/hub`
- 正式域名目标：`portal.braunblinds.com`
- WordPress 官网 `braunblinds.com` 继续作为公开官网，业务门户与官网分离。
- 三个旧门户逐步停止独立开发，稳定后统一重定向。

## 真实性原则

- GitHub 代码完成不等于线上部署完成。
- 没有真实部署和测试，不宣称已上线。
- 不使用假订单、假客户或假统计数据填充正式页面。
- 支付、物流和云服务密钥只存储在部署环境，不写入仓库。
