# BRN-014 Business Intelligence — 验收清单

## A. 真实性与数据来源

- [ ] 驾驶舱不显示演示 KPI 或静态假数字。
- [ ] 所有指标只使用正式业务记录。
- [ ] Excel 暂存、回滚和失败导入不计入 KPI。
- [ ] 每个指标显示数据截止时间。
- [ ] 每个汇总数字可下钻到来源记录。

## B. 指标口径

- [ ] 草稿和取消订单不计入确认销售额。
- [ ] void/cancelled Invoice 不计入有效开票。
- [ ] 已收金额按有效付款减退款计算。
- [ ] 应收余额与 Invoice 明细之和一致。
- [ ] USD 支出与 RMB 支出分别统计。
- [ ] 缺少汇率时不生成虚假的统一利润。
- [ ] 使用汇率时显示汇率、日期、来源和版本。

## C. 权限

- [ ] Owner 可查看全部经营和利润数据。
- [ ] Sales 只能查看授权范围，不显示内部成本。
- [ ] Factory 只能查看分配给自己的生产指标。
- [ ] Installer 只能查看自己的安装统计。
- [ ] Customer 无法访问内部经营分析 API。
- [ ] 直接调用 API 不能绕过页面权限。

## D. 时间与筛选

- [ ] 今天、本周、本月、季度、年度和自定义日期正确。
- [ ] 时区边界不会把订单计入错误日期。
- [ ] 客户、销售、产品、工厂、承运商和安装工筛选正确。
- [ ] 下钻继承原筛选条件。
- [ ] 环比和同比使用相同口径。

## E. 财务

- [ ] 部分付款、退款、超额付款显示正确。
- [ ] Stripe、Zelle、支票、现金和 ACH 分类正确。
- [ ] 原币金额不被换算值覆盖。
- [ ] 作废支出不计入成本。
- [ ] 财务数据修改后相关缓存失效。

## F. 运营

- [ ] 工厂逾期按承诺日期判断。
- [ ] 物流区分报价、实际费用和客户运费。
- [ ] 多箱运费和箱规统计正确。
- [ ] 安装完工必须符合照片/签字规则。
- [ ] 返工和取消任务不被误算为正常完工。

## G. 数据质量

- [ ] 缺失币种、汇率和订单关联显示警告。
- [ ] 无数据与金额为 0 能正确区分。
- [ ] 聚合失败时显示上次成功截止时间。
- [ ] 不完整数据不会静默显示为完整。

## H. API 与性能

- [ ] API 返回 `dataAsOf`、`isComplete`、`warnings` 和 `metricVersion`。
- [ ] 明细接口分页，最大 100 条。
- [ ] 常用驾驶舱首屏目标 3 秒内返回。
- [ ] 大型导出使用异步任务。
- [ ] 导出文件包含筛选、时间、币种和数据截止说明。

## I. AI 集成

- [ ] AI 使用统一指标层，不重复定义公式。
- [ ] AI 回答附订单、Invoice 或报表来源。
- [ ] AI 无权限时拒绝返回利润或其他敏感数据。
- [ ] 数据不完整时 AI 明确说明，不猜测。

## J. 发布前

- [ ] 指标定义已版本化并完成业务确认。
- [ ] 使用真实订单、付款、支出、物流和安装数据对账。
- [ ] 测试环境完成至少一个完整月份的复算。
- [ ] 数据库、缓存、后台任务和导出存储已配置。
- [ ] GitHub 合并、数据库迁移和生产部署状态分别记录。
- [ ] 代码合并不被表述为网站已经上线。
