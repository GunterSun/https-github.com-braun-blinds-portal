# BRN-004 Quote / Invoice / Payment Center — 验收测试

## 1. Quote

- Braun、Jin、手工和导入来源均可生成 Quote 草稿。
- 多产品、数量、尺寸、单价和备注保存正确。
- 折扣、税、安装费、运费和总额与服务端公式一致。
- Quote 版本化；已发送版本不会被后续修改覆盖。
- 客户版本不显示批发价、内部成本或利润。
- Quote 接受后只生成一个订单，重复请求幂等。

## 2. Invoice 编号与版本

- Invoice 编号为五位数且唯一。
- 并发生成不会重复编号。
- 已签发 Invoice 修改时创建新版本或调整流程。
- Billing 和工程地址使用历史快照。
- Void 不删除历史记录，并保留原因和操作人。

## 3. PDF

- 一页 Invoice 在常见明细数量下保持一页。
- 超出一页时分页合理，表头与合计不丢失。
- PDF 文字清晰、行高合理、手机和打印可读。
- 文件大小大于零，可打开并下载。
- 客户、公司、订单、Invoice、金额和币种与数据库一致。
- 空白 PDF、缺字段或总额不一致时返回失败。

## 4. 付款

- 支持 Stripe、Zelle、Check、Cash、ACH、Wire。
- 定金、部分付款和多笔付款正确更新 `amount_paid` 与 `balance_due`。
- 全额付款后状态变为 Paid；不足金额不得标记 Paid。
- 超额付款显示待处理余额，不静默丢弃。
- 一笔付款可按规则分配多个 Invoice。
- 退款和撤销保留原付款，并正确重算余额。
- 重复参考号、重复幂等键和重复 Stripe event 被拦截。

## 5. Stripe

- Checkout 金额来自服务端实时余额。
- webhook 错误签名被拒绝。
- 同一事件重复发送只处理一次。
- 浏览器跳转 success 页面不会单独将 Invoice 标记 Paid。
- 手续费、毛收款和净收款字段正确。

## 6. 币种与计算

- 所有销售金额明确标记 USD 或配置币种。
- RMB 工厂支出不会进入客户 Invoice。
- USD 与 RMB 不会直接相加。
- 小数舍入规则在单行、税和总额中一致。
- 空金额保持空；未知币种阻止签发。

## 7. 权限

- Owner 可访问全部功能。
- Sales 只能访问分配范围。
- Factory 和 Installer 无法读取价格、付款和利润接口。
- Customer 只能读取自己的公开文档和付款状态。
- 直接调用 API 也不能绕过权限。

## 8. 发送与联系记录

- Quote、Invoice、Receipt 发送前有完整预览。
- 收件人、主题、正文和附件正确。
- 发送成功与失败均保存记录。
- 重试不会重复生成 Invoice 或付款。

## 9. 审计与恢复

- 金额、状态、付款、退款、作废和发送均有审计日志。
- 数据库事务失败不会留下部分付款或半生成 Invoice。
- PDF 或邮件服务故障不影响订单核心数据。
- 数据库迁移包含备份、回滚和旧数据校验步骤。

## 10. 设备与上线

- 手机、平板和电脑可以创建、查看和发送 Quote/Invoice。
- 关键按钮有加载、成功、失败和防重复点击状态。
- 测试环境使用测试 Stripe key；生产环境不混用。
- GitHub 合并、数据库迁移、测试环境验证、生产部署和域名状态分别确认。

只有全部关键测试通过，且真实订单试运行由 Owner 验收后，BRN-004 才可标记为已完成。
