# BRN-019 — 验收测试

## 1. 状态真实性

- 合并 PR 后只显示 `merged`，不能自动显示正式上线。
- staging 成功、production 失败时两个环境状态必须不同。
- DNS 未验证时不得显示正式域名可用。
- 数据库迁移未执行时必须醒目标记。

## 2. 发布闸门

- 构建失败时禁止进入生产部署。
- Critical 或 High 数据问题存在时默认阻止发布。
- 没有备份或回滚方案时禁止破坏性迁移。
- 未通过 staging 验收时禁止提升到 production。
- 非 Owner 不能批准生产发布或回滚。

## 3. 关键回归测试

- Owner、Sales、Factory、Installer、Customer 权限隔离。
- 五位数订单和 Invoice 正常生成与搜索。
- Quote 转订单、Invoice、部分付款和已付款状态正确。
- Stripe 重复 webhook 不产生重复付款。
- USD 与 RMB 不被直接相加或误标。
- Excel 相同文件被 SHA-256 拦截。
- 导入回滚不删除已生成且有关联的正式记录。
- PDF 为空时生成失败。
- 手机端关键按钮可操作且有反馈。

## 4. 数据健康

- 能发现重复客户和重复订单候选。
- 能发现缺失币种和不明确币种。
- 能发现已付款但余额不为 0。
- 能发现付款总额大于 Invoice 且无超额付款处理。
- 能发现孤立的物流、安装和支出记录。
- 问题可下钻到来源文件、工作表、行号或正式记录。

## 5. 修复安全

- 自动扫描不得修改数据。
- 修复前显示修改前后差异。
- 相同幂等键重复提交只执行一次。
- Owner 取消后不产生任何写入。
- 批量修复失败时事务回滚并保存错误。

## 6. 回滚

- 回滚预览显示代码、数据库和数据影响。
- 备份不可用时阻止回滚。
- 回滚完成后重新运行健康检查和关键流程测试。
- 回滚失败时状态显示 failed/partial，不能显示成功。

## 7. 发布完成标准

- 自动测试通过。
- 人工验收有测试人和证据。
- 数据质量闸门通过。
- 数据库迁移与备份验证完成。
- production 健康检查通过。
- `portal.braunblinds.com` 实际访问和登录验证通过。
- 发布说明、已知问题和回滚记录完整。
