# BRN-011 Inventory / Warehouse Center — 验收测试

## 1. 主数据

- 创建 SKU、条码、单位、类别和供应商。
- 验证重复 SKU、重复序列号和无效单位被拦截。
- 验证面料批次、颜色批号和卷号可追溯。
- 验证电机序列号和保修日期可查询。

## 2. 入库

- 采购单全部到货、部分到货和超收场景。
- 实收数量、损坏数量和隔离数量分别正确。
- 同一确认请求重复发送只生成一次入库流水。
- 未确认收货可以取消，已确认收货不能直接删除。

## 3. 预留与并发

- 为订单创建库存预留后，可用库存正确减少。
- 两个订单同时预留最后一件库存时，仅一个成功。
- 订单取消后未消耗预留正确释放。
- 预留过期策略不影响已确认生产或发货任务。

## 4. 出库与退库

- 按订单预留进行完整和部分出库。
- 无库存、单位错误、批次缺失和序列号重复时阻止出库。
- 退库生成反向流水并恢复可用库存。
- 报废不会返回可用库存，并要求审批和原因。

## 5. 调拨

- 仓库间调拨依次经过草稿、发出、在途、接收。
- 发出仓减少、在途增加、接收后目标仓增加。
- 部分接收和运输损坏能独立记录。

## 6. 盘点

- 盘点任务保存账面快照。
- 实盘一致时不产生调整流水。
- 差异必须审核后才生成调整。
- 已批准盘点不能再次批准。
- 盘点期间发生的正常业务流水不会被静默覆盖。

## 7. 数量与单位

- 卷、码、英尺、英寸、套、个和箱显示正确。
- 未配置转换关系时禁止自动换算。
- 轨道或杆件切割后原料减少、余料形成可追踪记录。
- 空数量保持为空，不能自动变为零。

## 8. 成本和币种

- USD 与 RMB 成本层分别保存。
- 不提供汇率时不生成混合币种库存价值。
- 修改成本不改变库存数量。
- 销售、工厂、安装工和客户不能查看未授权成本。

## 9. 权限

- Owner 可查看和审批全部库存操作。
- Sales 只能查看允许范围的可用库存和预留。
- Factory 只能访问分配工厂的物料任务。
- Installer 只能查看分配安装任务的携带材料。
- Customer 无法访问内部库存、成本和库位。
- 所有权限必须在服务端验证。

## 10. 条码与移动端

- 手机扫描条码能打开正确 SKU。
- 收货、领料、盘点和调拨模式不会互相混淆。
- 重复扫描给出清晰提示，不重复入账。
- 手机、平板和电脑页面均可完成关键流程。

## 11. 审计、恢复和性能

- 每笔流水保存用户、时间、来源和关联订单/采购单。
- 错误更正使用反向流水，不删除历史。
- 可从库存流水重建余额并与当前余额一致。
- 大量 SKU 和流水下搜索、分页和导出正常。
- API 或扫码中断时不产生半完成库存交易。

## 12. 发布闸门

发布前必须通过数据库迁移备份、回滚演练、并发预留测试、权限测试、USD/RMB 测试和真实仓库小范围试运行。代码合并不等于功能已部署；必须在正式域名验证入库、预留、出库和盘点流程。
