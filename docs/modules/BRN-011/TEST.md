# BRN-011 Workflow Engine — 验收清单

## A. 权限

- [ ] 未登录用户无法访问流程 API。
- [ ] Owner 可配置、暂停、重试和审批授权动作。
- [ ] Sales 只能操作分配订单的销售流程。
- [ ] Factory 只能更新分配给自己的工厂步骤。
- [ ] Installer 只能更新分配给自己的安装步骤。
- [ ] Customer 不能查看内部成本、审批、错误详情或流程配置。

## B. 标准订单流程

- [ ] Quote 接受后只生成一个订单确认事件。
- [ ] 未满足生产条件时不创建正式工厂任务。
- [ ] Invoice 支持定金、部分付款和全额付款状态。
- [ ] 工厂完成后可进入物流草稿，但不自动购买运单。
- [ ] 到货后可创建安装草稿，但变更排期需要确认。
- [ ] 安装完工后触发余额检查、回访草稿和财务结算待办。

## C. 幂等

- [ ] 相同 `eventId` 第二次提交不会重复执行。
- [ ] Stripe webhook 重复到达不会生成重复付款。
- [ ] 重试 Invoice 步骤不会生成第二张 Invoice。
- [ ] 重试消息步骤不会重复发送已经成功的消息。
- [ ] Tracking 重复更新不会重复提醒。

## D. 审批

- [ ] 高风险动作先显示完整预览。
- [ ] 审批 token 绑定用户、对象、动作和过期时间。
- [ ] 对象在审批前发生变化时，旧 token 失效并重新预览。
- [ ] AI Agent 无法自行批准动作。
- [ ] 拒绝审批保存原因并停止或转入人工处理。

## E. 财务与币种

- [ ] 每个金额明确显示 USD 或 RMB。
- [ ] USD 与 RMB 不自动相加。
- [ ] 付款不足时不标记为 paid。
- [ ] 退款、撤销和超额付款不由普通流程自动执行。
- [ ] 手工付款需要金额、币种、方式、日期、参考号和操作人。

## F. 状态机

- [ ] 非法状态跳转被服务端拒绝。
- [ ] 已发出的 Invoice 不被静默修改。
- [ ] 已完成步骤保留历史，不因模板升级被改写。
- [ ] 订单归档不破坏付款、支出、物流和审计关联。

## G. 失败与恢复

- [ ] 可重试错误按策略重试并记录次数。
- [ ] 不可重试错误进入人工处理队列。
- [ ] 暂停后不执行后续步骤。
- [ ] 继续时重新校验权限和业务条件。
- [ ] 外部 AI、邮件、Stripe 或物流服务故障时，门户订单功能仍可用。
- [ ] 部分失败不会留下无法识别的半完成财务状态。

## H. 安全

- [ ] 客户端传入角色被忽略。
- [ ] Excel、PDF、邮件和备注中的指令不能修改流程定义。
- [ ] 日志不包含密钥、密码、Session token 或完整信用卡信息。
- [ ] API 错误不返回 SQL 或服务器堆栈。
- [ ] 流程模板仅允许白名单业务动作。

## I. 页面与可用性

- [ ] `/workflows` 显示模板和启停状态。
- [ ] `/workflows/runs` 支持状态、订单和异常筛选。
- [ ] 订单流程页面显示时间线、下一步和待审批。
- [ ] 手机、平板和电脑可以操作审批和任务更新。
- [ ] 中文和英文切换后关键状态含义一致。

## J. 发布前检查

- [ ] 数据库迁移已创建流程定义、运行、步骤、事件和审批表。
- [ ] 对关键事件建立唯一约束和幂等索引。
- [ ] 使用真实测试订单完成一次端到端演练。
- [ ] 使用重复 webhook 完成幂等演练。
- [ ] 完成暂停、失败、重试和恢复演练。
- [ ] 备份数据库并记录回滚计划。
- [ ] GitHub 合并、数据库迁移、部署和 DNS 状态分别记录。
