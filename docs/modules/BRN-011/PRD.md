# BRN-011 Inventory / Warehouse Center — 产品需求

## 1. 目标

建立 Braun Smart Portal 的统一库存与仓库中心，管理面料、电机、轨道、罗马杆、配件、成品、包装材料和退货品，连接采购、订单、工厂、物流和财务模块。

系统必须以真实库存流水为依据，不允许使用演示库存或手工修改汇总数字代替库存交易。

## 2. 核心范围

- 仓库、库区、货架和库位管理。
- SKU、条码、单位、规格、品牌、供应商和图片。
- 面料卷按卷号、批次、颜色和剩余码数管理。
- 电机与智能配件按型号、序列号和保修状态管理。
- 轨道、窗帘杆和超长材料按长度、数量和可切割余料管理。
- 包装箱、护角、胶带和标签等耗材管理。
- 采购入库、客户退货、工厂退回和库存调整。
- 订单领料、出库、调拨、报废、退库和盘点。
- 订单库存预留，防止同一库存被重复分配。
- 最低库存、安全库存和补货提醒。

## 3. 关键业务流程

### 3.1 入库

采购单或工厂到货后创建待收货记录。仓库人员核对 SKU、数量、单位、批次、损坏和实际库位后确认入库。部分到货必须保留未收数量。

### 3.2 订单预留与领料

订单确认后可生成预留草稿。预留不会减少实物库存，但会减少可用库存。实际领料或发货时生成出库流水。取消订单时释放未使用预留。

### 3.3 盘点

支持全仓、库区、库位和指定 SKU 盘点。盘点差异必须经过授权确认并形成调整流水，不能直接覆盖账面数量。

### 3.4 退货和报废

客户退货、工厂退回和损坏品必须进入隔离状态，经检查后决定重新入库、返工、退供应商或报废。

## 4. 页面

- `/inventory`：库存总览、搜索和预警。
- `/inventory/items/[sku]`：SKU 详情、库存和流水。
- `/warehouse/receipts`：收货与入库。
- `/warehouse/issues`：领料、出库和退库。
- `/warehouse/transfers`：仓库及库位调拨。
- `/warehouse/counts`：盘点任务和差异审批。
- `/warehouse/returns`：退货、隔离、返工和报废。
- `/settings/warehouses`：仓库、库位和权限设置。

## 5. 权限

- Owner：查看全部库存价值、成本、调整、盘点和审计。
- Sales：查看可销售或可预留数量，不查看受限成本。
- Factory：仅查看和更新分配给本工厂的领料、退料或工厂库存。
- Installer：仅查看分配任务需要携带的材料和签收状态。
- Customer：不访问内部库存；只能看到允许公开的有货或交期状态。

## 6. 业务规则

- `on_hand`、`reserved`、`available` 必须分别保存和计算。
- 可用库存 = 实物库存 - 有效预留 - 隔离库存。
- 任何库存变化必须由不可变流水产生。
- 数量必须带单位，卷、码、英尺、英寸、套、个和箱不能静默混用。
- USD 和 RMB 成本分开保存；库存数量不因汇率变化而改变。
- 库存不足时不得生成虚假成功的领料或出库结果。
- 重复扫描、重复 webhook 或重复请求只能产生一次有效流水。

## 7. 完成标准

至少完成一个采购入库、一个订单预留、一个实际出库、一个退库和一次盘点差异流程；所有数量可追溯到流水；权限、移动端扫码、并发预留和回滚测试通过。
