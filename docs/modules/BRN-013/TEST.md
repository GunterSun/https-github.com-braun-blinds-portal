# BRN-013 Developer Platform — 验收清单

## A. 应用与凭证

- [ ] 只有 Owner 或授权管理员可创建应用。
- [ ] 密钥只在创建时完整显示一次。
- [ ] 数据库不保存可直接读取的明文密钥。
- [ ] 密钥可轮换、撤销和设置到期日。
- [ ] 被撤销应用立即无法调用 API。
- [ ] 前端、日志和错误响应不出现密钥。

## B. OAuth 与 Scope

- [ ] Authorization Code + PKCE 正常工作。
- [ ] Redirect URI 必须精确匹配。
- [ ] Token 过期和撤销后不可继续使用。
- [ ] 应用只能调用已授权 Scope。
- [ ] `orders:read` 不能执行订单写入。
- [ ] Scope 不会绕过角色、客户归属和订单分配。

## C. API

- [ ] 所有响应包含 request ID。
- [ ] 列表接口有分页和最大条数。
- [ ] 输入错误返回标准错误结构，不泄露堆栈。
- [ ] USD 与 RMB 分别返回，不被直接相加。
- [ ] 无权限字段不会出现在响应中。
- [ ] 写操作记录操作人、应用和对象审计。

## D. 幂等

- [ ] 同一幂等键重复创建 Invoice 只生成一张。
- [ ] 同一幂等键重复记录付款只生成一笔。
- [ ] 相同键但参数不同返回冲突。
- [ ] 超时后客户端重试不会产生重复业务记录。

## E. Webhook

- [ ] Webhook 包含事件 ID、类型、时间和模式。
- [ ] HMAC 签名可正确验证。
- [ ] 错误签名和过期时间戳被拒绝。
- [ ] 事件接收端可按事件 ID 去重。
- [ ] 非 2xx 投递自动重试。
- [ ] 达到上限后进入死信状态。
- [ ] Owner 可查看脱敏投递历史并人工重放。
- [ ] 密钥轮换期间新旧密钥按规定窗口工作。

## F. 插件

- [ ] 安装前展示权限和外部域名。
- [ ] 未经 Owner 批准的插件不能启用。
- [ ] 插件升级新增 Scope 时必须重新批准。
- [ ] 停用后 API 和 Webhook 权限立即失效。
- [ ] 卸载不会删除正式订单、付款或物流记录。
- [ ] 插件不能执行任意服务器命令或访问未声明域名。

## G. 沙箱

- [ ] 沙箱和生产密钥完全分离。
- [ ] 沙箱不包含真实客户敏感资料。
- [ ] 沙箱付款和运单不会产生真实费用。
- [ ] 沙箱 Webhook 标记 `livemode=false`。
- [ ] 沙箱数据不能误写入生产数据库。

## H. 限流与故障

- [ ] 超过限流返回 429 和重试时间。
- [ ] 高风险写接口限制低于只读接口。
- [ ] 下游物流或邮件服务故障不会造成重复写入。
- [ ] 部分失败有明确状态和可恢复路径。
- [ ] API 服务异常时门户核心页面仍能安全降级。

## I. 文档与兼容性

- [ ] OpenAPI 与实际路由和 Schema 一致。
- [ ] CI 检查破坏性 API 变更。
- [ ] 弃用接口有迁移说明和停止日期。
- [ ] 示例不包含真实客户信息或密钥。
- [ ] GitHub 合并、数据库迁移、部署和 DNS 状态分别记录。

## J. 发布前

- [ ] 完成威胁建模和权限审查。
- [ ] 备份生产数据库。
- [ ] 使用测试应用完成订单查询、幂等写入和 Webhook 全流程。
- [ ] 验证 Stripe、物流、邮件和 AI 接入均使用最小权限。
- [ ] 建立密钥泄露应急和撤销流程。
- [ ] Owner 完成真实业务验收后才允许生产启用。
