# BRN-013 — 验收测试

## 1. 登录与账号

- 邀请链接一次使用并在到期后失效。
- suspended / disabled 用户无法登录。
- 禁用用户后已有会话立即失效。
- 密码重置不会暴露账号是否存在。
- Owner 高风险账号可强制启用双重验证。
- 系统拒绝禁用最后一个 active Owner。

## 2. 五级角色

### Owner

- 可查看全部授权业务数据和审计记录。
- 可管理用户、角色和临时授权。
- 高风险操作仍需确认和原因，不能因 Owner 身份跳过审计。

### Sales

- 只能读取和修改分配给自己的客户与订单。
- 无法查看未分配客户、其他销售私有备注和完整公司财务。
- 不能管理角色、密钥或正式发布。

### Factory

- 只能看到所属工厂被分配的任务。
- 看不到客户售价、利润、其他工厂成本和客户内部沟通。
- 不能修改订单、Invoice 或客户付款状态。

### Installer

- 只能看到本人或团队的安装任务。
- 可更新安装状态、照片、签字和异常。
- 看不到工厂成本、利润和不必要的客户资料。

### Customer

- 只能看到自己的或明确共享的 Quote、Invoice、订单和 Tracking。
- 看不到批发成本、利润、内部备注、其他客户和其他订单。
- 无法通过修改 URL、GraphQL 参数或 API 请求越权。

## 3. 数据范围

- `assigned`、`team`、`factory`、`self`、`customer-owned` 和 `shared-only` 逐项测试。
- 列表总数、搜索结果、导出和 AI 回答均遵守同一范围。
- 临时权限到期后立即失效。
- deny 规则覆盖 allow 规则。
- 资源重新分配后，旧用户访问权限立即更新。

## 4. 服务器端保护

- 前端手动显示隐藏按钮后，服务器仍拒绝无权请求。
- 直接调用 API 无法绕过权限。
- 后台任务、Webhook、AI Agent 和 Workflow 同样执行权限检查。
- 拒绝访问返回 403，不泄露资源是否存在的敏感细节。

## 5. 高风险操作

- 权限提升、财务导出、退款、批量修改和密钥轮换需要正确权限。
- 关键操作显示影响范围并要求明确确认。
- 临时授权必须有原因和到期时间。
- 服务身份不能授予超过其允许范围的权限。

## 6. 审计

- 登录成功、失败、会话撤销、权限允许和拒绝均记录。
- 角色变更保存修改前后快照、操作人和原因。
- 审计日志不可由普通管理员修改或删除。
- 日志不包含密码、MFA 密钥、完整令牌或支付密钥。

## 7. 并发与安全

- 两名管理员同时修改同一角色时检测版本冲突。
- 重复邀请和重复授权不会产生多条有效记录。
- 暴力登录、会话固定、CSRF、IDOR 和权限缓存失效测试通过。
- 手机、平板、电脑上的退出和会话撤销一致。

## 8. 回归测试

- Quote、Invoice、付款、财务、Excel 导入、工厂、仓库、物流、安装、AI 和发布中心均使用共享权限服务。
- Customer、Factory、Installer 的旧链接和旧 API 不再暴露越权数据。
- 权限服务暂时不可用时，高风险写入默认拒绝，不能默认放行。

## 9. 发布条件

- 权限矩阵由 Owner 验收。
- 自动化越权测试全部通过。
- 数据迁移前有用户、角色和分配关系备份。
- staging 使用测试账号覆盖五个角色。
- production 发布后验证登录、分配、撤权和审计关键流程。
