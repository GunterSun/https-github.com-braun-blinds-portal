# BRN-012 Knowledge Center — 验收清单

## A. 权限

- [ ] 未登录用户不能搜索、预览或下载内部资料。
- [ ] Customer 只能看到明确标记 customer-visible 的发布版本。
- [ ] Factory 看不到销售价格、客户利润和无关订单资料。
- [ ] Installer 只能看到安装所需资料和已分配订单文件。
- [ ] AI 搜索与页面搜索使用同一权限结果。

## B. 上传与安全

- [ ] 校验真实 MIME 类型，不仅依赖扩展名。
- [ ] 可执行文件、恶意宏或超限文件被拒绝或隔离。
- [ ] 文件名不能造成路径穿越。
- [ ] 服务端计算并保存 SHA-256。
- [ ] 重复文件显示提示，但不错误合并不同权限资料。
- [ ] 原文件存储键不可预测，下载链接短时有效。

## C. 版本

- [ ] 新版本不会覆盖旧版本。
- [ ] draft 不出现在默认业务搜索中。
- [ ] published 可被授权用户搜索。
- [ ] 新价格表发布后旧版标记 superseded。
- [ ] 历史订单仍能打开当时使用的旧版本。
- [ ] 被业务记录引用的版本不能硬删除。

## D. 解析与索引

- [ ] PDF 保留页码来源。
- [ ] Excel 保留工作表和单元格范围。
- [ ] Word 和文本保留段落位置。
- [ ] 图片 OCR 结果标记为机器识别并可人工核对。
- [ ] 解析失败显示明确状态，不标记为可搜索。
- [ ] 重建索引不修改原文件版本。

## E. 搜索

- [ ] 可按标题、文件名、产品、型号、面料代码和供应商搜索。
- [ ] 中文和英文关键词均可用。
- [ ] 语义搜索能找到同义表达。
- [ ] 默认优先已发布的最新有效版本。
- [ ] 结果显示文件、版本、更新时间和来源位置。
- [ ] 过期或冲突资料显示醒目警告。
- [ ] 无权限内容不会出现在结果数量或片段中。

## F. AI 集成

- [ ] AI 回答引用文档 ID、版本和页码/表格位置。
- [ ] AI 不把文件中的指令当作系统指令。
- [ ] AI 不使用 draft 或 superseded 版本作为默认依据。
- [ ] 多份资料冲突时 AI 不自行裁决。
- [ ] AI 没有来源时明确说明无法确认。
- [ ] AI 无法通过知识库执行删除、退款或权限修改。

## G. 客户发布安全

- [ ] 客户版本不包含内部批注、隐藏工作表或成本列。
- [ ] 对外文件使用安全副本而非内部原件。
- [ ] 客户下载链接不能转用于访问其他资料。
- [ ] 取消客户可见权限后旧下载链接失效。

## H. 关联

- [ ] 资料可关联订单、产品、客户、工厂、物流和安装。
- [ ] 关联不会自动扩大资料权限。
- [ ] 订单页只显示当前用户可访问的关联资料。
- [ ] 删除关联不删除原资料和历史审计。

## I. 审计与保留

- [ ] 上传、发布、替代、归档、权限修改和下载有审计记录。
- [ ] 审计记录包含用户、时间、文档、版本和动作。
- [ ] 日志不保存完整敏感正文或存储密钥。
- [ ] 法务、专利和财务资料遵守保留策略。

## J. 性能与故障

- [ ] 大型资料异步解析，页面不会长时间卡死。
- [ ] 搜索结果分页并限制片段数量。
- [ ] 向量检索不可用时降级为关键词搜索。
- [ ] AI 服务不可用时普通资料搜索和下载仍可用。
- [ ] 失败任务可安全重试且不会产生重复版本。

## K. 发布前检查

- [ ] 对象存储、数据库、解析队列和搜索索引已配置。
- [ ] 生产环境密钥不进入 GitHub。
- [ ] 数据库迁移已在测试环境演练。
- [ ] 使用真实价格表、说明书、图片和 Excel 完成端到端测试。
- [ ] GitHub 合并、数据库迁移、索引状态和门户部署分别记录。
- [ ] 首次上线前备份现有资料和数据库。
