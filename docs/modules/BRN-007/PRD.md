# BRN-007 Installation Operations — 产品需求

## 1. 目标
建立统一安装中心，把订单、客户地址、欠款、产品、安装工、排期、完工照片、客户签字、问题和售后记录连接到同一订单。

## 2. 核心功能
- 日历、列表、地图三种排期视图。
- 一个订单可有多次安装、补装或返工。
- 安装任务保存订单号、客户、地址快照、联系人、时间窗、产品、数量、安装说明、停车/门禁备注和所需工具。
- 安装工手机端查看当天分配任务并一键导航。
- 出发、到达、开始、暂停、完成、未完成、取消状态。
- 完工必须上传照片；可采集客户签字、完工备注和余额确认。
- 缺件、尺寸错误、墙体问题、客户不在、损坏和返工等异常单独记录。
- 完工后触发余额检查、回访、保修和利润更新。

## 3. 权限
- Owner：全部查看、分配、改期、取消、审核异常。
- Sales：查看和维护自己订单的安装信息，不可查看内部工资或全部利润。
- Installer：仅查看分配给自己的任务及完成所需信息。
- Factory：仅查看与返工或补件有关的必要内容。
- Customer：仅查看允许公开的预约时间和进度。

## 4. 安全原则
- 安装工不得看到批发成本、工厂成本、利润或其他客户资料。
- 地址、电话和门禁信息按任务最小化展示。
- GPS 仅在明确启用和任务期间使用，不做持续跟踪。
- 客户签字、照片和状态变更必须记录操作人和时间。

## 5. 完成标准
- 手机、平板和电脑可用。
- 任务、照片、签字、异常和订单时间轴完整关联。
- 离线或弱网时可保存草稿并在恢复网络后安全同步。
- 重复点击不得产生重复完工、重复照片或重复通知。
