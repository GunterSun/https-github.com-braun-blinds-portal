# BRN-007 Installation Operations — 验收测试

## 功能
- 创建、分配、改期、取消和完成任务。
- 一个订单支持初装、补装和返工多次任务。
- 日历、列表、地图和订单时间轴数据一致。
- 手机可查看地址、电话、产品、备注并启动导航。
- 前、中、后和异常照片可上传、预览和追溯。
- 客户签字保存正确，不能被普通用户覆盖。
- 未满足完成条件时，系统明确阻止完成并列出缺失项。

## 权限
- 安装工只能看到自己的任务。
- 安装工看不到客户批发价、工厂成本、利润和其他客户。
- Sales 只能操作授权订单。
- Customer 只能看到公开预约信息。
- 所有权限必须在 API 层验证。

## 状态与幂等
- 非法状态跳转被拒绝。
- 重复提交状态、照片、签字或完成请求不产生重复记录。
- 改期和取消保留完整历史。
- 多设备同时操作时使用版本或并发控制避免覆盖。

## 弱网与移动端
- 离线草稿恢复后可安全同步。
- 同一草稿重复同步只生成一次记录。
- iPhone、Android、平板和桌面关键流程可用。
- 图片压缩不影响原始文件追溯。

## 隐私与安全
- 未授权时不采集 GPS。
- GPS 仅限任务时间和最小必要精度。
- 文件类型、大小和恶意文件检查有效。
- 客户地址、电话和门禁信息不会泄露给无关用户。

## 业务联动
- 完工后订单时间轴、安装状态、余额检查和回访待办正确更新。
- 异常可创建补件、返工或新安装任务，但不会重复扣款或重复通知。
- 所有关键操作有用户、时间、来源和变更内容审计。
- staging 验收、数据库迁移、备份和回滚测试完成后才能发布。
