# BRN-003 Customer 360 / CRM — 验收测试

## 1. 客户主档

- 可创建个人和公司客户。
- 必填字段缺失时服务端拒绝。
- 客户编号唯一且不可由普通用户覆盖。
- 归档客户不会从历史订单、Invoice 或付款中消失。

## 2. 联系人与地址

- 一个客户可保存多个联系人和多类地址。
- 每类默认联系人/地址最多一个。
- 修改客户主地址不会改变历史 Invoice、物流和安装地址快照。
- 电话、邮箱和地址标准化不覆盖原始输入。

## 3. 搜索

- 姓名、公司、电话、邮箱和地址均可找到客户。
- 订单号、Invoice 和 Tracking 能反查客户。
- 手机端搜索和筛选可用。
- 无权限客户不出现在结果中。

## 4. 订单与财务

- 客户详情显示真实订单、Quote、Invoice、付款和余额。
- 部分付款和退款后余额正确。
- USD 与 RMB 分列显示，不能直接相加。
- 所有汇总可下钻到来源记录。

## 5. 客户的客户

- 批发客户可建立终端客户资料。
- 终端客户 Quote/Invoice 不显示批发价、成本或利润。
- Customer 角色无法通过 API 参数获取隐藏字段。

## 6. 联系记录

- 电话、短信、邮件、微信、面谈和备注可记录。
- 草稿不会显示为已发送。
- 重复发送请求被幂等保护。
- 联系记录正确关联客户和可选订单。

## 7. 重复客户

- 相同电话、邮箱或地址产生重复候选。
- 系统不会未经确认自动合并。
- 合并预览列出字段冲突和关联记录数量。
- 合并使用事务；模拟失败后数据保持原状。
- 合并完成后订单、文件和联系记录指向主客户，并保留审计。

## 8. 权限

- Owner 可查看全部并执行合并。
- Sales 只能查看分配范围。
- Factory 不可见客户欠款、利润和内部备注。
- Installer 只看到任务所需联系人、地址和安装备注。
- Customer 只能查看本人及公开内容。
- 服务端直接 API 测试不能绕过权限。

## 9. 文件与隐私

- 客户只能下载标记为可见的文件。
- 工程照片和内部文件按角色隔离。
- 文件上传检查类型、大小和安全状态。
- 敏感字段不出现在日志和错误响应中。

## 10. 发布前检查

- 数据库迁移有备份和回滚步骤。
- 旧客户数据导入先预览、去重和审核。
- 页面在手机、平板和电脑通过测试。
- 不存在演示客户、假订单、假欠款或无反应按钮。
- 代码合并、数据库迁移和线上部署状态分别确认。
