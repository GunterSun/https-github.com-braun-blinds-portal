# BRN-003 Customer 360 / CRM — 产品需求

## 1. 目标

建立统一客户档案，将客户联系人、电话、邮箱、地址、客户的客户、订单、Quote、Invoice、付款、欠款、折扣、工程照片、联系记录和备注集中管理。系统不得因姓名拼写、电话号码格式或不同 Excel 来源重复创建同一客户。

## 2. 页面

- `/customers`：客户列表、搜索、筛选和重复提示。
- `/customers/[customerId]`：Customer 360 工作区。
- 标签：概览、联系人、地址、订单、报价与 Invoice、收款与欠款、联系记录、文件与照片、备注、审计。

## 3. 客户主档

保存：

- 客户类型：零售、批发、设计师、承包商、商业客户、其他。
- 公司名、显示名、法律名称。
- 主要联系人、电话、邮箱。
- Billing、Shipping、Project 地址，可有多条。
- 税务状态、默认折扣、默认付款条款。
- 销售负责人、客户状态、来源和标签。
- 首次合作、最后订单、累计订单和当前欠款。

## 4. 客户的客户

批发客户可为自己的终端客户保存姓名、电话、邮箱、地址和项目备注。终端客户版本的 Quote/Invoice 不得显示批发价、内部成本或利润。

## 5. 联系记录

支持电话、短信、邮件、微信、面谈和内部备注。每条记录保存时间、操作人、摘要、关联订单和后续任务。发送动作必须使用受控流程，不能把草稿标记为已发送。

## 6. 搜索与去重

支持姓名、公司、电话、邮箱、地址、订单号、Invoice 和 Tracking 搜索。电话需标准化但保留原始格式。潜在重复依据包括相同电话、邮箱、标准化地址或高度相似名称；合并必须由 Owner 或授权人员确认。

## 7. 权限

- Owner：全部客户、财务、合并和审计。
- Sales：分配客户及相关订单；不得查看未授权利润。
- Factory：仅查看生产所需信息，不显示客户财务和利润。
- Installer：仅查看分配任务所需联系人、地址和安装备注。
- Customer：仅查看本人及明确公开的订单、Quote、Invoice、付款和文件。

## 8. 关键规则

- 客户主档是订单、Quote、Invoice 和联系记录的唯一客户来源。
- 历史订单不得因客户资料更新而失去当时的账单或项目地址快照。
- 删除采用归档；有订单或财务记录的客户不可硬删除。
- 客户合并保留来源、旧 ID、操作人和完整审计。
- USD 与 RMB 仍分别显示，不在客户总览中静默相加。
- 禁止演示客户、假订单和静态欠款。

## 9. 完成标准

- 客户列表、详情、创建、编辑和归档可用。
- 一个客户可关联多联系人、多地址和多订单。
- 搜索、重复提示和受控合并通过测试。
- 五级权限在服务端执行。
- 所有客户数据来自真实数据库并可下钻核对。
