# BRN-002 统一订单中心验收清单

## A. 唯一订单

- [ ] 同一五位数订单号不能创建两条主订单。
- [ ] `68735`、`CWF68735`、`CWF 68735` 搜索到同一订单。
- [ ] 同一订单下多个产品明细均被保留。
- [ ] Quote、Invoice、付款、支出、物流和安装均关联同一 `order_id`。

## B. 权限

- [ ] Owner 可访问全部订单和内部财务。
- [ ] Sales 只能访问自己被分配或允许的订单。
- [ ] Factory 不能看到客户售价、付款、利润和其他工厂成本。
- [ ] Installer 只能看到被分配安装任务和必要现场信息。
- [ ] Customer 只能看到自己的订单、Quote、Invoice、付款、物流与安装。
- [ ] 直接调用 API 也无法绕过页面权限。

## C. 订单工作区

- [ ] 概览显示客户、订单状态、应收、已收、余额和下一步任务。
- [ ] 产品标签支持多个产品、尺寸、数量、面料和备注。
- [ ] Quote 支持版本并保留已发送版本。
- [ ] Invoice 显示五位数编号、PDF、总额和付款状态。
- [ ] 工厂、物流、安装、文件和日志标签可以正常读取与操作。
- [ ] 不存在假订单、假 KPI 或点击无反应的按钮。

## D. 付款

- [ ] 一张 Invoice 支持多笔付款。
- [ ] 定金后状态为 `partial`，余额正确。
- [ ] 全额付款后状态为 `paid`，余额为 0。
- [ ] 超额付款标记为 `overpaid`，不静默截断金额。
- [ ] 退款不覆盖原付款记录。
- [ ] Stripe 重复 webhook 不会重复入账。
- [ ] 手工付款保存方式、参考号、日期和操作人。

## E. 多币种成本

- [ ] USD 支出显示美元符号并保存 USD。
- [ ] RMB 支出显示人民币符号并保存 RMB。
- [ ] 系统不会自动把 RMB 当成 USD。
- [ ] 无明确汇率时，不显示虚假的统一美元利润。
- [ ] 使用汇率计算时保存汇率和日期。
- [ ] 多工厂、多加工费和多运费均可分别录入。

## F. 状态

- [ ] 订单主状态与付款状态独立。
- [ ] 非法状态跳转被拒绝或要求 Owner 确认。
- [ ] 已取消订单不会被统计为有效销售。
- [ ] 已完成订单仍可查看完整历史。
- [ ] 归档不会删除付款、支出、文件或日志。

## G. 搜索

- [ ] 可按订单号、CWF 格式和 Invoice 号搜索。
- [ ] 可按客户姓名、电话、邮箱和地址搜索。
- [ ] 可按 Tracking 搜索到对应订单。
- [ ] 搜索结果遵守角色权限。
- [ ] 空搜索和无结果状态正常显示。

## H. Excel 导入

- [ ] BRN-005 暂存记录不会自动创建正式订单。
- [ ] `commit-preview` 显示将创建、关联、跳过和警告的记录。
- [ ] 相同订单号的不同产品明细不会被去重删除。
- [ ] 无订单号支出进入待匹配状态。
- [ ] 合并汇款不会自动错误分摊。
- [ ] 正式生成记录保存 import batch/row 来源。
- [ ] 重复执行 commit 不会生成重复业务记录。

## I. 审计和安全

- [ ] 创建、修改、状态变化、付款、支出、归档和分配均写入日志。
- [ ] API 错误不泄露密钥、SQL 和堆栈。
- [ ] 金额汇总由服务端计算，篡改前端请求不能改变总额。
- [ ] 已开具 Invoice 后修改产品会触发版本或调整流程。
- [ ] 客户不可下载未标记为可见的内部文件。

## J. 设备与性能

- [ ] 手机、平板和电脑可使用订单工作区。
- [ ] 大量产品、付款和日志时页面仍可分页和滚动。
- [ ] 订单列表分页有效，最大页数限制有效。
- [ ] 页面加载失败有明确错误和重试方式。

## K. 发布前

- [ ] 数据库迁移脚本经过测试并可回滚。
- [ ] 旧订单数据完成备份和迁移预演。
- [ ] 使用真实订单样本完成端到端测试。
- [ ] Owner、Sales、Factory、Installer、Customer 五种账号均通过验收。
- [ ] GitHub 合并、数据库迁移、部署、DNS 和线上验证分别记录。
