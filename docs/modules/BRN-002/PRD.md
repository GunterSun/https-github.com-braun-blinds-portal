# BRN-002 统一订单中心 PRD

## 1. 目标

以唯一订单号为核心，把客户、报价、Invoice、付款、工厂、采购、物流、安装、文件和利润集中到同一个订单工作区。系统不得为同一业务订单建立互相独立、无法同步的多份记录。

## 2. 核心原则

- 一个业务订单只有一个主订单记录。
- 五位数字订单号为主要业务识别号，例如 `68735`。
- `CWF68735`、`CWF 68735` 和 `68735` 可作为外部显示或搜索别名，但必须指向同一主订单。
- Quote、Invoice、付款、工厂任务、物流和安装均通过 `order_id` 关联。
- 同一订单可以有多个产品明细、多个工厂支出、多个加工费、多个运费和多次付款。
- USD 与 RMB 原币分别保存；利润换算必须使用明确汇率和换算日期。
- 删除订单必须采用归档或受控软删除，禁止直接破坏财务与审计链路。

## 3. 订单工作区

订单详情页建议路径：`/orders/[orderNumber]`。

页面标签：

1. 概览：客户、状态、应收、已收、成本、利润、下一步任务。
2. 客户：联系人、电话、邮箱、工程地址、客户的客户信息。
3. 产品：Braun/Jin 计算结果、尺寸、数量、款式、面料、安装方式和备注。
4. Quote：版本、折扣、税、安装费、备注及客户版本。
5. Invoice：五位数编号、金额、到期日、PDF、付款状态。
6. 收款：Stripe、Zelle、支票、现金、ACH、其他方式；支持定金和部分付款。
7. 工厂与采购：多工厂、材料款、加工费、付款日期、币种、生产状态。
8. 物流：多箱尺寸重量、承运商、费用、Tracking、预计和实际到货。
9. 安装：排期、安装工、导航地址、完工照片、签字和售后。
10. 财务：USD 收入、USD 支出、RMB 支出、汇率、毛利和未核对项目。
11. 文件与图片：订单相关 PDF、Excel、图片、视频和邮件附件。
12. 操作日志：创建、修改、付款、导入、状态变更和权限操作。

## 4. 订单状态

建议主状态：

- `draft` 草稿
- `quoted` 已报价
- `confirmed` 已确认
- `in_production` 生产中
- `ready_to_ship` 待发货
- `shipped` 已发货
- `installation_scheduled` 已排安装
- `installed` 已安装
- `completed` 已完成
- `cancelled` 已取消
- `on_hold` 暂停

付款状态独立保存：`unpaid`、`partial`、`paid`、`refunded`、`overpaid`。

## 5. 权限

- Owner：查看和修改全部订单、成本、利润、付款、删除和重新分配。
- Sales：查看被分配订单；维护客户、产品、报价和沟通；默认不可查看全部内部利润。
- Factory：只查看分配给自己的生产资料，不查看客户售价、利润和其他工厂成本。
- Installer：只查看分配的安装信息、必要欠款提示、地址和现场资料。
- Customer：只查看自己的 Quote、Invoice、付款、物流和安装状态；不得查看成本与利润。

## 6. 搜索

全局搜索应支持：

- 五位数订单号
- CWF 订单号
- Invoice 号
- 客户姓名、公司、电话、邮箱
- 工程地址
- Tracking
- 工厂名称

## 7. Excel 导入关系

BRN-005 暂存记录只有在 Owner 审核后才能生成或关联订单。系统必须：

- 优先匹配标准化订单号。
- 不因相同订单号删除不同产品明细。
- 无订单号的支出保留为待匹配记录。
- 合并汇款不自动拆分。
- 所有生成记录保存 `import_batch_id` 与 `import_row_id`。

## 8. 验收完成定义

- 一个订单页面能够查看完整业务链路。
- 所有子记录通过主订单关联。
- 五级角色权限通过测试。
- USD/RMB 不混淆。
- 部分付款和多笔成本正确汇总。
- 无假数据、假按钮或不可操作页面。
- 数据库迁移、测试、部署和回滚方案均已记录。
