# BRN-008 Finance Center — 验收测试

## 1. 币种

- USD 收入、USD 支出和 RMB 支出分别汇总。
- 缺少币种的记录不能进入正式账目。
- 未指定汇率时不显示统一利润。
- 指定汇率后仍保留原币金额、汇率和日期。

## 2. Invoice 与付款

- Invoice 总额、部分付款、多笔付款、退款和余额可复算。
- 重复 Stripe webhook 只生成一条有效付款。
- 同一幂等键重复提交不产生重复付款。
- void 和退款不覆盖原始记录。

## 3. 支出

- 一个订单可保存多个工厂、材料、加工、运费和安装支出。
- 支出类别、供应商、币种和付款状态正确。
- void 支出不参与有效汇总，但仍可审计。
- Excel 同一来源行不能重复生成支出。

## 4. 利润

- 订单利润能下钻到收入和每条支出。
- 缺失支出或币种不明时显示数据不完整警告。
- 月度、客户、产品和销售员汇总使用同一计算服务。
- AI 助理与老板驾驶舱结果一致。

## 5. 对账

- 未匹配付款进入待处理区。
- 匹配操作先预览再确认。
- 重复参考号、重复金额和异常日期产生警告。
- 已锁账期间不能直接修改，必须使用调整记录。

## 6. 权限

- Customer 只能查看自己的 Invoice、付款、退款和余额。
- Factory 看不到客户销售价和利润。
- Installer 看不到不相关财务数据。
- Sales 默认看不到内部工厂成本和利润。
- 所有越权 API 请求返回拒绝且不泄露数据。

## 7. 安全与审计

- API 不返回密钥或完整敏感账号。
- 金额、币种、汇率、退款、void、匹配和锁账都有审计记录。
- 失败写入不会留下部分数据。
- 备份、迁移和回滚在测试环境验证。

## 8. 设备与发布

- 手机、平板和电脑可查看关键财务页面。
- 大量数据使用分页和服务端聚合。
- 测试环境通过后再部署正式环境。
- 合并代码、数据库迁移和正式上线状态分别记录。
