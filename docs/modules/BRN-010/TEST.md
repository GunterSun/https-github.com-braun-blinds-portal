# BRN-010 验收测试

## 1. 主流程

- 创建 Jin 和 KT 两个供应商，分别设置默认 RMB 与 USD。
- 将同一订单的不同产品或数量分配给两个工厂。
- 分别更新生产、质检、发货和完成状态。
- 生成采购单、审批、发送、部分付款和全额付款。
- 订单工作台正确汇总各工厂进度，但不重复计算成本。

## 2. 币种与金额

- RMB 费用始终显示人民币标识，USD 费用始终显示美元标识。
- 未明确币种的 Excel 行不得直接生成正式费用。
- 缺少汇率时不得显示合并后的美元利润。
- 修改批准金额不会覆盖原始报价。

## 3. 权限

- Factory A 不能查看 Factory B 的任务。
- Factory 用户看不到客户售价、利润、内部付款备注和完整客户资料。
- Sales 未经授权不能确认供应商付款。
- Installer 只能看到与安装准备有关的到货状态。
- Customer 无法访问工厂和采购接口。

## 4. 重复与数据安全

- 相同参考号、金额、币种和供应商的付款触发重复警告。
- 重复 API 请求不会生成第二张采购单或第二笔付款。
- 已付款采购单不能硬删除。
- 撤销付款保留原始付款与撤销记录。
- Excel 导入来源行可追溯到文件、工作表和行号。

## 5. 异常

- 超期、缺料、尺寸问题、返工和破损可以建立质量/异常记录。
- 工厂任务暂停后不会被自动标记完成。
- 发货缺少 Tracking 或交接说明时显示警告。
- 状态迁移错误返回明确提示，不静默失败。

## 6. 设备与发布

- 手机、平板和电脑可查看和更新授权任务。
- 中英文切换不丢失状态。
- 数据库迁移有备份和回滚方案。
- staging 使用真实结构的测试数据通过后才允许 production。
- 合并代码不得被描述为已上线，必须验证正式域名和真实权限。
