# BRN-010 Braun AI Agent — 验收清单

## A. 权限

- [ ] Owner 可查看和配置全部 Agent。
- [ ] Sales、Factory、Installer、Customer 只能运行被授权的 Agent。
- [ ] 计划任务不能使用超过创建者权限的系统身份。
- [ ] Customer 无法读取内部成本、利润或其他客户数据。

## B. 数据与币种

- [ ] 每个金额显示明确币种。
- [ ] USD 与 RMB 不直接相加。
- [ ] 缺少汇率时不生成统一利润结论。
- [ ] 没有数据时明确说明，不编造结果。
- [ ] 结果提供可访问的数据来源链接。

## C. 草稿与写入

- [ ] Level 1 内容清楚标记为草稿。
- [ ] 草稿不会自动发送给客户、工厂或安装工。
- [ ] Level 2 操作先返回修改预览。
- [ ] 未确认时数据库没有变化。
- [ ] 确认 token 绑定用户、动作、对象和参数。
- [ ] token 过期、重复使用或数据变化后被拒绝。
- [ ] 写入请求重复提交不会生成重复记录。

## D. 禁止操作

- [ ] Agent 不能自动删除正式订单、付款或支出。
- [ ] Agent 不能自动退款或转账。
- [ ] Agent 不能修改角色、密码、密钥或 Stripe 设置。
- [ ] Agent 不能直接提交未经审核的 Excel 暂存数据。

## E. 各 Agent 基础测试

- [ ] Sales Agent 能从已确认产品生成 Quote 草稿。
- [ ] Customer Service Agent 能生成英文和中文付款提醒草稿。
- [ ] Finance Agent 分币种列出逾期和未结算项目。
- [ ] Factory Agent 只返回授权工厂任务。
- [ ] Logistics Agent 保存并引用箱规、重量和历史费用。
- [ ] Installation Agent 只返回分配给当前安装工的任务。
- [ ] Owner Agent 经营日报的数字可追溯到真实记录。
- [ ] Project Manager Agent 检查 PR 对应文档、测试和发布状态。

## F. 计划任务

- [ ] 只有 Owner 可创建财务和批量计划。
- [ ] 时区和运行频率正确。
- [ ] 可暂停、恢复和关闭计划。
- [ ] 运行量超过上限时停止并提示。
- [ ] 同一计划重复触发不会重复写入。

## G. 安全

- [ ] PDF、Excel、邮件和备注中的指令不会改变 Agent 权限。
- [ ] Agent 不使用自由 SQL 或万能数据库工具。
- [ ] API 不返回密码、Session、密钥或内部堆栈。
- [ ] 外部工具失败时不以猜测补全结果。

## H. 审计

- [ ] 每次运行记录 Agent、版本、用户、触发方式和权限范围。
- [ ] 工具调用和访问对象可追踪。
- [ ] 草稿、确认、拒绝和写入结果均有记录。
- [ ] 写入前后值可审计。

## I. 故障与发布

- [ ] AI 服务不可用时核心门户仍可使用。
- [ ] 部分失败不会留下不一致业务状态。
- [ ] 测试环境先使用真实订单副本验证。
- [ ] 生产启用前设置调用上限、超时和成本监控。
- [ ] GitHub 合并、部署、数据库迁移和 Agent 启用状态分别记录。
