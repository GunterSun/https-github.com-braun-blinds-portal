# BRN-010 Braun AI Agent — 产品需求

## 1. 目标

在 BRN-009 AI 助理的只读查询和受控写入基础上，建立面向实际业务流程的多智能代理系统。Agent 可以主动检查任务、生成建议和草稿，但不得绕过用户权限、人工确认或审计规则。

## 2. Agent 类型

- 销售 Agent：报价草稿、产品建议、Quote/Invoice 草稿。
- 客服 Agent：订单进度回复、付款提醒、物流通知草稿。
- 财务 Agent：欠款、异常付款、未结算支出和利润预警。
- 工厂 Agent：待生产、超期、材料与加工费提醒。
- 物流 Agent：箱规核对、历史运费比较和承运商建议。
- 安装 Agent：排期、地址、欠款、完工资料提醒。
- 老板 Agent：经营日报、风险事项和待处理清单。
- 项目经理 Agent：检查 GitHub PR 是否符合项目文档、测试和发布规则。

## 3. 操作分级

- Level 0：只读查询、汇总和提醒。
- Level 1：生成 Quote、Invoice、邮件、短信、采购、物流和安装草稿。
- Level 2：需用户明确确认后写入，例如更新订单状态、记录付款、创建安装任务。
- Level 3：禁止 Agent 自动执行，包括删除正式记录、退款、修改权限、密钥、银行或 Stripe 设置、批量覆盖数据库。

## 4. 主动任务

Agent 可按计划运行：

- 每日上午生成老板日报。
- 每日检查逾期 Invoice、未发货订单和当日安装。
- 发现物流异常、生产超期或数据缺失时生成提醒。
- 检查新 PR 是否包含对应 BRN 文档、测试清单和发布说明。

主动任务只能在用户或 Owner 明确启用后运行，并允许暂停、修改频率和关闭。

## 5. 业务原则

- 所有数据来自统一门户数据库和经过权限检查的业务工具。
- 每个金额必须标明 USD 或 RMB，禁止默认合并。
- Agent 不得把建议写成已执行结果。
- 所有草稿必须清楚标记“草稿”。
- 所有受控写入必须显示修改前、修改后、影响对象和确认人。
- Agent 不得直接操作旧门户或独立数据源形成新的数据孤岛。

## 6. 用户界面

- `/ai-agents`：Agent 总览、启用状态和最近运行。
- `/ai-agents/runs`：运行历史、结果、错误和确认记录。
- 订单、客户、物流、安装和财务页面提供上下文 Agent 操作。
- Owner 可配置每个 Agent 的权限、频率、通知渠道和最大处理数量。

## 7. 完成标准

- 至少一个只读 Agent 和一个草稿 Agent 完整通过测试。
- 所有 Agent 继承五级权限。
- 所有写入都经过预览和确认。
- Agent 服务不可用时，门户核心业务仍可正常使用。
- 运行历史、工具调用和确认结果可审计。
