# BRN-010 Factory / Purchasing / Supplier Center — 产品需求

## 1. 目标

把 Jin、KT 及其他工厂、供应商的生产、采购、成本、付款、交期、质检和发货统一关联到正式订单，避免继续分散在多个 Excel、聊天和门户中。

## 2. 核心能力

- 工厂与供应商主档：名称、联系人、电话、微信、邮箱、地址、币种、付款条款、交期和备注。
- 一个订单可拆分给多个工厂，每个工厂任务独立记录产品、数量、材料、加工、预计完成日和状态。
- 支持材料采购、补料、加工费、样品费、包装费、国内运费、国际运费和其他费用。
- 每笔费用必须保存 USD 或 RMB，不允许默认改币种。
- 支持采购单、工厂任务、付款申请、付款记录、质检、发货和异常处理。
- 工厂只看到分配给自己的任务，不得看到客户售价、利润、其他工厂资料或完整客户隐私。

## 3. 状态

工厂任务状态：草稿、待确认、已下单、生产中、待质检、待发货、已发货、已完成、暂停、取消。

采购单状态：草稿、待审批、已发送、部分到货、已到货、部分付款、已付款、取消。

## 4. 页面

- `/factories`：工厂与供应商列表。
- `/factories/[id]`：联系人、历史订单、付款、交期和质量记录。
- `/factory-orders`：全部生产任务。
- `/purchase-orders`：采购单与付款状态。
- `/orders/[orderNumber]/factory`：单个订单的多工厂工作区。

## 5. 业务规则

- 五位数订单号是唯一关联依据。
- 同一费用不能因 Excel 导入、人工输入或付款回写而重复生成。
- 工厂报价、批准成本和实际成本分开保存。
- 取消或调整正式费用必须保留原记录和审计轨迹。
- 工厂发货必须记录箱数、Tracking 或交接信息。
- 生产延期、缺料、尺寸争议和质量问题必须形成异常记录。

## 6. 权限

- Owner：全部查看、审批、修改和付款确认。
- Sales：查看分配订单进度；是否可见成本由 Owner 配置。
- Factory：仅查看和更新分配任务的生产、质检、发货资料。
- Installer：默认不可见工厂成本，只能查看与安装有关的到货状态。
- Customer：不得查看工厂、供应商、采购和内部成本。

## 7. 完成标准

至少支持一个订单同时分配 Jin 和 KT，分别记录 RMB/美元成本、交期、付款和发货；所有权限、币种、审计、重复拦截和移动端流程通过验收。
