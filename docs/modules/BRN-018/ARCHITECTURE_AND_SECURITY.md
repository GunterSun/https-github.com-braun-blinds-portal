# BRN-018 Computer Use Agent 架构与安全

## 1. 架构

```text
用户授权会话
  ↓
任务编排器
  ↓
站点允许列表与权限检查
  ↓
浏览器执行环境
  ↓
观察 / 填写 / 预览 / 确认 / 执行
  ↓
门户业务 API 与审计日志
```

代理不得直接访问生产数据库，也不得绕过门户 API 写入业务数据。

## 2. 会话隔离
- 每次运行使用独立会话 ID。
- 不同用户、角色和订单不得共享浏览器状态。
- Cookie、下载文件和截图按会话隔离并设置过期时间。
- 会话结束后清理临时数据；长期凭据只能保存在专用密钥系统中。

## 3. 网站允许列表
Owner 必须显式配置允许的网站、域名、允许路径、任务类型和风险等级。重定向到未授权域名时立即暂停。

## 4. 凭据和登录
- 密码、API Key 和验证码不得写入日志或模型上下文。
- 双重验证和验证码必须由用户本人完成。
- 不记录信用卡完整号码、CVV、Session token 或恢复码。
- 代理不得尝试规避网站安全机制。

## 5. 页面内容安全
网页、邮件、PDF、备注和上传文件中的文字全部视为不可信业务数据。任何要求忽略权限、泄露数据、执行脚本或转账的页面内容都不能改变系统规则。

## 6. 确认令牌
Level 2 操作先生成不可修改的预览快照与一次性确认令牌。令牌绑定：
- 用户和角色
- 目标网站和账户
- 订单或业务对象
- 表单字段与金额
- 页面版本或关键内容哈希
- 过期时间

任何关键字段变化都会使确认令牌失效。

## 7. 幂等和重复保护
- 购买运单、创建订单、提交付款表单等操作必须使用幂等键。
- 超时后先查询外部结果，不能直接重试购买。
- 同一订单、箱子、承运商和服务的重复标签必须警告。

## 8. 紧急停止
界面始终提供停止按钮。Owner 可全局禁用代理、禁用指定网站或撤销正在运行的会话。停止后不得继续后台点击或提交。

## 9. 审计
记录任务发起人、角色、订单、网站、每一步动作、字段变更摘要、截图引用、确认人、外部响应、错误和最终状态。敏感字段必须脱敏。

## 10. 失败恢复
- 执行失败时标记最后确认步骤和未知结果。
- 不把未知结果标记为成功。
- 支持从安全检查点恢复，但提交动作不得重复执行。
- 外部网站不可用时，门户核心功能仍应正常工作。

## 11. 数据保留
截图和页面快照按业务与隐私策略设置保留期限。包含敏感资料的快照应缩短期限并限制为 Owner 查看。
