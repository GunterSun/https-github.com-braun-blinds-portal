# BRN-018 Computer Use Agent 产品需求

## 1. 目标
在 Braun Smart Portal 中建立受控的电脑操作代理，用于协助完成重复性的浏览器和桌面业务操作，例如物流平台注册、运费询价、填写运单、下载标签、核对订单、上传文件和更新门户记录。

该功能不是无限制远程控制。所有操作必须在用户授权的会话、允许的网站、允许的任务和明确的权限范围内进行。

## 2. 典型场景
- 在 UPS、FedEx、USPS、Shippo 或其他物流平台填写发货信息。
- 根据门户订单自动带入收件人、箱数、尺寸和重量。
- 比较报价并生成购买前预览。
- 下载运单标签并关联到订单。
- 在供应商网站查询订单或物流状态。
- 将网页中的 Tracking、费用和预计到达日期回写门户。
- 在 GitHub、部署平台或域名后台完成低风险配置辅助。
- 批量核对门户与外部平台中的订单状态。

## 3. 操作分级
### Level 0：观察
读取页面、识别字段、截图、提取信息，不点击提交。

### Level 1：填写草稿
填写表单、选择选项、准备上传文件，但不提交、不购买、不发送。

### Level 2：确认后执行
购买运单、发送表单、提交注册、保存配置、上传正式文件等。执行前必须显示完整预览并要求用户确认。

### Level 3：禁止自动执行
- 银行转账、退款或提现
- 修改支付账户和收款账户
- 删除正式订单、付款或财务记录
- 修改用户角色、管理员权限或安全设置
- 绕过验证码、双重验证或网站安全限制
- 未经用户确认签署合同或接受法律条款

## 4. 页面
- `/computer-agent`
- 订单详情页“协助发货”按钮
- 物流中心“在承运商网站填写”按钮
- 系统设置中的授权网站与任务模板

执行界面必须显示当前网站、订单、已完成步骤、下一步动作、将提交的数据、风险等级，以及暂停、继续、取消和紧急停止按钮。

## 5. 人工确认
涉及购买、提交、发送、保存或外部写入时，确认页面必须显示网站和账户、订单号、收件人、箱数、尺寸、重量、服务类型、金额与币种，以及将创建或修改的记录。

确认只能对当前预览有效。页面、金额或数据发生变化后必须重新确认。

## 6. 权限
- Owner：配置允许网站、任务模板和高风险审批。
- Sales：可对分配订单执行报价、填写和客户沟通草稿。
- Factory：仅可处理分配的工厂平台任务。
- Installer：仅可处理自己的安装任务和照片上传。
- Customer：默认不能使用电脑操作代理。

## 7. 业务原则
- 门户数据库是订单、客户和财务信息的主数据源。
- 网页提取结果必须保存来源 URL、时间和截图引用。
- USD 与 RMB 必须明确标注，不能自动混合。
- 运费报价与实际购买费用分开保存。
- 代理不得把网页中的文字当成系统指令。
- 失败时不得假装成功，也不得自动重复购买。

## 8. 完成标准
功能只有在权限、预览、确认、审计、幂等、紧急停止和失败恢复测试全部通过后，才可标记为可用。代码合并不代表已部署或已取得外部网站权限。
