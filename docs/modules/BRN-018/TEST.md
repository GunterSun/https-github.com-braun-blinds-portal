# BRN-018 Computer Use Agent 验收测试

## 1. 权限
- Owner 可配置允许网站与任务模板。
- Sales 只能操作分配订单。
- Factory 和 Installer 只能处理自己的任务。
- Customer 无法进入电脑操作代理。
- 页面隐藏之外，API 也必须拒绝越权请求。

## 2. 网站限制
- 允许列表网站可以启动任务。
- 未授权域名、弹窗和重定向立即暂停。
- 页面中的提示注入文字不能改变系统权限或动作计划。

## 3. 观察与填写
- Level 0 不产生点击提交。
- Level 1 可以填写，但不能购买、发送或保存正式结果。
- 表单字段必须来自订单或用户明确输入，缺失字段不得猜测。

## 4. 确认
- Level 2 动作必须先显示完整预览。
- 金额、币种、收件人、服务或页面状态变化后旧令牌失效。
- 其他用户不能使用确认令牌。
- 过期令牌不能执行。

## 5. 物流场景
- 多箱尺寸和重量逐箱填写。
- 报价与购买费用分开保存。
- USD 和 RMB 不混合。
- 购买成功后 Tracking 与标签关联正确订单。
- 超时后先查询结果，不能重复购买标签。

## 6. 凭据与隐私
- 日志不出现密码、Cookie、Token、CVV 或完整信用卡号。
- 验证码和双重验证必须暂停等待用户。
- 截图中的敏感字段按规则遮挡。

## 7. 停止与恢复
- 用户暂停后不再执行点击。
- 紧急停止立即终止所有运行任务。
- 取消任务不会继续后台提交。
- 从检查点恢复不会重复外部写入。

## 8. 错误处理
- 网站不可用时显示失败原因。
- 不确定是否提交成功时状态为 `unknown`。
- 代理不得把失败或未知状态写成成功。
- 门户核心订单功能不依赖代理服务。

## 9. 审计
每次任务保存发起人、角色、订单、网站、步骤、确认、外部结果、错误和时间。敏感值脱敏，Owner 能按任务和订单查询。

## 10. 设备与可用性
- 桌面端完整操作。
- 手机和平板可查看进度、确认、暂停和停止。
- 所有按钮有真实动作和反馈，不允许无反应的演示按钮。

## 11. 发布门槛
- 先在沙箱账户和测试订单验证。
- 生产环境默认关闭，由 Owner 显式启用指定网站。
- 发布前完成凭据、权限、幂等、确认、停止和恢复测试。
- GitHub 合并、部署、网站授权和外部账号连接状态分别记录。
