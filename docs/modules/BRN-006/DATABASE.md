# BRN-006 数据模型

## Shipment
保存订单关联、发件地址快照、收件地址快照、承运商、服务、状态、Tracking、报价金额、购买金额、最终账单金额、币种、预计和实际到货时间、外部平台编号及幂等键。

## ShipmentPackage
每个包裹保存序号、长宽高、尺寸单位、实际重量、重量单位、计费重量、包装类型、最长边、周长和超长标识。

## ShippingRate
保存承运商、服务等级、报价、币种、预计时效、附加费、有效期、平台 Rate ID 和查询时间。

## TrackingEvent
保存承运商原始状态、门户统一状态、时间、地点、说明、外部事件编号和去重摘要。

## ShippingCharge
保存基础运费、超长费、地址更正费、住宅费、燃油费、退款等费用项目，关联物流和财务记录。

## 关键约束

- 已购买运单必须保留地址和箱规快照。
- 报价、购买金额和最终账单金额分别保存，不相互覆盖。
- 所有金额必须标明 USD 或 RMB。
- 外部事件和购买请求必须去重。
- 取消、退款和重新购买不得删除原始记录。
- 同一有效 Tracking 不得无审核绑定到多个订单。
- 尺寸、重量和包裹数量必须通过服务器校验。

Shipment 与 Order、Customer、Warehouse、Expense 和 AuditLog 关联。
