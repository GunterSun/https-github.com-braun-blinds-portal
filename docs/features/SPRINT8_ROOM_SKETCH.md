# Sprint 8 — Room Sketch (#140)

Room Sketch reuses the canonical Property, Room, Window and Measurement records introduced by Smart Measure.

- Touch, pencil and mouse pointer dragging with a visible grid and 2% snapping.
- Walls, doors, sliding doors, stairs, fireplace, TV, furniture, outlets, switches, beams and obstacles.
- Real Window records can be placed once and remain linked by permanent ID.
- Undo, redo, duplicate, rotation, width/height annotations and immutable saved versions.
- Customer view hides object and room internal notes.
- Installer has read-only access; Owner and authorized Sales can edit.
- Every sketch is marked as an orientation aid unless its scale is explicitly measured and approved.

Photo attachment remains tracked with the Smart Measure media work in #139.
