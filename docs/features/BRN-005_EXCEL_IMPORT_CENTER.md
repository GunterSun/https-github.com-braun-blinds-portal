# BRN-005 Excel 导入中心

## 1. 目标

把 Braun Blinds 现有的真实 Excel 数据安全导入统一门户，同时避免币种混淆、重复导入、误覆盖和不可逆修改。

## 2. 当前支持的文件

- `批发销售*.xlsx`
  - 汇总
  - Paul
  - 林
  - 彭
- `jin汇总*.xlsx`
  - Commerce订单汇总

## 3. 核心流程

1. Owner 选择 Excel 文件。
2. 浏览器计算文件 SHA-256。
3. 系统识别工作簿类型。
4. 解析并标准化记录。
5. 显示订单、支出、付款、警告、USD 和 RMB 汇总。
6. Owner 核对后确认导入到暂存区。
7. 服务端按文件哈希拦截重复导入。
8. 暂存区保留来源文件、工作表、原始行号和原始数据。
9. Owner 可在导入历史中查看批次并安全回滚。
10. 只有逐条审核通过后，才能生成正式订单、付款或支出记录。

## 4. 业务规则

- USD 与 RMB 必须分开保存和汇总。
- 不允许自动把人民币转换成美元。
- 空金额保持空值，不自动填写 0。
- 异常长数字不得自动作为金额。
- `CWF67635` 规范化为 `CWF 67635`。
- 同一 PO 下不同产品明细不得因订单号相同而被删除。
- 合并汇款先保留原始说明，不自动分摊。
- `汇总` 页部分支出币种不明确时必须标记警告，不能直接进入正式账目。
- 每条导入记录必须保存来源文件、工作表、行号和原始行内容。

## 5. 权限

- Owner：上传、预览、确认、查看历史、回滚。
- Sales / Factory / Installer / Customer：无权访问导入中心和导入 API。

## 6. 数据状态

- `preview`：仅前端预览。
- `confirmed`：已写入导入暂存区。
- `committed`：已生成正式业务记录。
- `rolled_back`：暂存批次已回滚。

## 7. 安全要求

- 相同 SHA-256 文件不得重复确认。
- 单次最多 5,000 条标准化记录。
- 已生成正式业务记录的批次禁止直接回滚。
- 所有确认和回滚必须写入审计日志。
- 代码合并不代表数据库迁移或外部门户已部署。

## 8. 页面

- `/data-import`：上传、解析、预览、确认。
- `/data-import/history`：批次历史和安全回滚。
