# Sprint 8 — Fabric Library (#143)

The Fabric Library provides one permanent SKU identity with immutable technical and price versions. Production consumers must use the versioned usable width, repeat and direction fields. Rendering assets are references only and always carry a screen-color disclaimer. Supplier cost is returned only to Owner. Active duplicate SKUs are rejected for review. Inventory lot/roll identity is ready for later MRP consumption.

Direct R2 uploads, version editing, lot-entry UI and downstream Design Studio/MRP selectors remain tracked under #143 and their dependent issues.
