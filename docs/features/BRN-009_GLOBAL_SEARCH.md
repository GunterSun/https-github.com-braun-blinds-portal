# BRN-009 全局搜索

## 目标

从统一门户通过一个搜索框定位权限范围内的真实订单、客户、Invoice、电话、邮箱和地址。Tracking 与工厂名称只在对应正式数据实体上线后接入，不使用假数据占位。

## 权限

- Owner：搜索全部统一订单、客户、地址和 Invoice。
- Sales：搜索本人负责或被分配的客户、订单和地址。
- Factory / Installer：只搜索被分配订单，结果不显示客户电话、邮箱或内部财务。
- Customer：只搜索自己的客户资料和订单。
- 权限在 API 服务端执行；隐藏页面或按钮不能替代数据过滤。

## 搜索规则

- 至少输入 2 个字符，最多 120 个字符。
- 支持五位数订单号、`CWF68735`、项目、客户、电话、邮箱和地址片段。
- Owner 可搜索五位数 Invoice。
- 每类结果限制数量，避免一次扫描或返回大量敏感数据。
- 空查询、超长查询和未登录请求必须被拒绝。

## 验收

- 搜索结果来自 D1 真实记录并能打开对应详情页。
- 不同角色使用相同关键词时，只返回各自有权访问的记录。
- 手机、平板和桌面均可操作。
- 搜索不到时明确显示空状态，不生成推测结果。
