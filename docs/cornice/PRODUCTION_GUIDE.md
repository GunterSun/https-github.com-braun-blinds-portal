# Braun International, LLC — Upholstered Cornice Production Guide
Version 1.2 — customer measurement and factory review

## Construction
- Solid wood top board; lightweight wooden batten frame for face and sides.
- Upholstery batting and exterior fabric. No nailhead trim or decorative studs on the bottom.
- Hinges, fastening, structural strength, brackets and transportation joints require factory confirmation before production.

## Seven approved styles
1. Linear — rectangular
2. Arch — continuous upward curved bottom
3. Casual — central recessed bottom
4. Deco — stepped bottom
5. Wide Scallop — broad curved scallop
6. Scallop — multiple scallops
7. Partial Arch — shallow localized arch

Refer to the customer-supplied original reference image for exact styling. Generated silhouettes are schematic only.

## Customer dimensions (inches)
- W: overall finished width.
- H: maximum finished height (tallest location).
- D: return depth, from wall to front face.
- A/B/C: shape-specific cutout depths, spans and positions. Record additional measurements and a verified curve template when needed.
- All non-rectangular dimensions must be reviewed by the factory. A schematic is not a CNC cutting file.

## Pricing (USD)
Base = 90 + 3 * max(0, W - 30)
Height multiplier: 4 <= H <= 9 => 1; 9 < H <= 15 => 1.10; 15 < H <= 20 => 1.20.
Style multiplier: Linear => 1; all six other styles => 1.20.
Total = Base * Height multiplier * Style multiplier.
Outside height range or unresolved production constraints: manual review.

## Workflow
1. Customer selects style and enters W/H/D and shape measurements.
2. Export or print a dimension and quote sheet.
3. Customer confirms all measurements and the drawing.
4. Factory reviews frame joints, materials, load, shipping length, curves and mounting.
5. Production begins only after the approved factory drawing and commercial order are confirmed.

## Important
The public drawing tool provides reference elevations only; it does not generate validated 1:1 machining drawings. No automated production release.
