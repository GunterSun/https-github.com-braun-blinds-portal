# 角色与权限

## Owner

查看和管理全部客户、订单、报价、Invoice、收款、工厂、采购、物流、安装、财务、利润、用户、数据导入和系统设置；可回滚未生成正式记录的导入批次。

## Sales

管理被授权的客户、报价和订单；查看相关 Invoice、付款、物流和安装；不能查看公司整体利润、其他销售的客户或系统密钥。

## Factory

只查看分配给本工厂的生产订单、产品规格、材料要求、截止日期和允许显示的文件；可更新生产状态和上传照片；不能查看客户售价、收款和利润。

## Installer

只查看分配的安装任务、客户地址、联系电话、时间和必要的欠款提醒；可导航、上传照片、签字和完工；不能查看工厂成本和整体财务。

## Customer

只查看自己的 Quote、订单、Invoice、付款、Tracking、安装安排和可下载资料；不能查看批发成本、内部备注、工厂资料和利润。

## 通用规则

- 默认拒绝，明确授权后开放。
- 所有订单 API 必须验证角色和订单分配。
- 停用账号立即撤销 Session。
- 删除、付款、导入、回滚和权限修改写入审计日志。
- 菜单隐藏不能替代服务端权限检查。
